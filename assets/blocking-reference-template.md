# 非GPT工具双站位图模板

用于Gemini简化九宫格失败后，或其他生图工具的默认稳定路线。

## 站位俯视图

```text
生成[项目名] [EPXX] 镜头[001]的单张站位俯视参考图。
场景：[场景编号＋名称]。严格保留参考场景图的入口、出口、固定家具、墙体和三个空间锚点，不重新设计环境。
人物：[人物编号＋人物名字]位于[位置]，身体朝向[方向]；[人物编号＋人物名字]位于[位置]，身体朝向[方向]。
标出每名人物的起点、移动路线和终点；标出摄影机位置、拍摄方向、180度轴线、关键道具位置和不可跨越障碍。
画面采用垂直俯视或高位近似平面视角，空间关系优先，线条和箭头清楚，人物只作为带名字的简洁站位符号。禁止增加人物、改变左右、改变场景结构或生成电影海报。
```

## 正面站位图

```text
生成[项目名] [EPXX] 镜头[001]的单张正面站位参考图。
保留参考场景图的完整物理结构、纵深和光影不变，只增加以下人物：
[人物编号＋人物名字]位于画面[左／中／右]侧[前景／中景／后景]，穿[锁定服装]，身体朝向[对象]，手持[道具及持物手]，动作停在[可见状态]。
[人物编号＋人物名字]位于画面[位置]，穿[锁定服装]，身体朝向[对象]，动作停在[可见状态]。
所有人物脸、发型、服装和身高关系严格继承角色卡；清楚显示左右站位、前后层次、遮挡关系、视线和人物间距离。禁止增加人物、交换位置、重新设计场景、改变服装或道具。
```
