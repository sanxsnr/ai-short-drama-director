# Seedance 2.0短剧视频提示词模板

所有方括号都必须替换；没有对应素材或字段时删除整句。最终只交付代码块内的自然语言提示词。

```text
参考@图片1中“[人物名字]”的人物长相、发型和服装；场景结构与光影参考@图片2；参考@图片3中“[道具名字]”的外观、尺寸和材质；参考@图片4九宫格从左上到右下的动作顺序、构图、人物调度和运镜逻辑，九格属于同一连续镜头，不代表九次切镜；动作节奏和摄影机移动参考@视频1，不继承其中人物与场景；[人物名字]的声线参考@音频1。

生成一段[10秒／15秒]的[题材]视频。场景为[场景名称与必要空间锚点]。[人物名字＋可识别外观]位于[位置、朝向和当前状态]；[人物名字＋可识别外观]位于[位置、朝向和当前状态]。

0—[X]秒：[景别、运镜、人物动作、构图和反应。]
[X]—[Y]秒：[连续动作、位置变化、对白和对方反应。]
[Y]—[总时长]秒：[动作完成、运镜变化和自然收束。]

对白：[人物名字]（[语气]）：“[完整台词]。”[其他人物台词按顺序继续；无对白写“无对白”。]
声音：[环境声、动作音效、音乐、声线和对白可懂度。]
画面：[全局风格、光线、材质、色调和必要画质。]
要求：[人数、身份、左右、服装、道具、场景和文字等当前最可能失败的3—8项约束。]
```

不得出现I2V、FLF2V、WAN、VACE、首帧、尾帧、CUT、TAIL、END FRAME、XML、自检日志或其他视频模型版本。
