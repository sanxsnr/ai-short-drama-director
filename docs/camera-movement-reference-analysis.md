# 运镜导演方法对照报告

## 目的

本报告比较当前`ai-short-drama-director`与两个外部参考Skill的运镜方法，并记录本项目最终采用的独立规则。外部材料只作为方法参考；最终规则必须兼容本项目既有的SEG／SHOT／CUT、世界坐标、180度轴线、动作状态机和任务覆盖体系。

## 对照表

| 对照项 | 修改前当前Skill | Emily体系 | MapleShaw体系 | 本项目采用方案 |
|---|---|---|---|---|
| 运镜动机 | 能识别推拉摇移及连续阶段，但主动动机较弱 | 先读场景功能、转折、POV、权力和潜台词，再让摄影机服务一个意图 | 主要解决摄影机状态和运动编码 | 每次先写`narrative_function`和`reason`；“增强电影感”不能单独成立 |
| 固定／运镜／CUT决策 | CUT与运镜边界明确，但缺少统一选择Gate | 选择能把观众放到正确心理位置的镜头行为 | 提供运动类型和组合冲突 | 新增`CAMERA_DECISION_GATE_V1`：先判断任务、时空、观察对象、连续路径、时长和CUT叙事优势 |
| 起始构图 | 可在运镜阶段写`start_state` | 强调start frame | Z/Y/X可编码起始位置 | 必须写起始机位区、方向、高度、景别和主体关系 |
| 运动路径 | 由04验证连续几何，但提示合同不够完整 | 要求movement physically possible | 把运动视为距离／高度／方位随时间变化 | 写`path_description`、`spatial_axes`、障碍与轴线状态；04仍是空间硬真源 |
| 速度变化 | 有自然语言运镜，但缺少阶段速度合同 | 明确speed | 有节奏层和冲突检查 | 写开始／中段／结束速度，禁止同段同时“缓慢＋快速”而无阶段说明 |
| 主体关系 | 04和14已有主体与机位关系 | 强调subject relationship | 坐标系统提供位置关系 | 运镜全过程必须写主体关系及是否保持关键动作可见 |
| 终点构图 | `end_state`存在 | 强调endpoint | 坐标可表示终点 | 必须写终点机位区、方向、高度、景别、主体关系 |
| 终点锁定 | 固定时间流逝已有锁定要求 | endpoint是完整镜头合同的一部分 | 未形成独立锁定Gate | 新增`lock_after_move`与`lock_duration_seconds`；时间流逝前必须锁定 |
| 多轴冲突 | 未形成统一可执行上限 | 反对在短镜头堆叠互相打架的运动 | 明确三轴同动风险、近距大旋转等 | 普通SEG最多一个主轴＋一个辅轴；高速动作例外仍需理由和可读性 |
| AI可执行性 | 已检查穿墙、越轴、动作覆盖和焦段歧义 | 偏向短、明确、单一摄影机概念 | 强调稳定和防漂移 | 把动机、起点、路径、速度、终点、锁定、动作可见性全部结构化并由验证器执行 |

## 来源内容与项目推导的边界

### 来源明确支持

- Emily的`seedance-camera`明确要求短片段使用清楚的主要摄影机概念，并为运镜写起始画面、运动、速度、主体关系和终点。
- Emily的`directing-engine`把摄影机运动解释为观众心理冲动，并要求所有工种服务同一个场景意图。
- MapleShaw的`camera-codec`把摄影机分为远近、高低、方位和镜头属性，并把运镜理解为坐标随时间变化；其冲突表明确指出三轴同时变化和互相矛盾的运动具有高风险。

### 本项目重新设计

- `locked／movement／cut_to_new_shot`三选一决策合同。
- 将04的世界坐标、关系轴与障碍物硬约束接入运镜路径验证。
- 将14的阶段任务、动作证据和可见性接入运镜过程。
- 将13保留为显式CUT后的相邻SHOT几何审核，不让15越权判断30度或CUT类型。
- 精确焦段仍只作`focal_feel`辅助，不作为CUT、运镜或空间硬判断。
- 对普通SEG设置“一个主运动轴＋最多一个辅轴”，高速动作根据动作链单独审核。

## 最终职责链

```text
01：剧情、动作、对白和时长
→ 04：世界坐标、允许区、障碍、关系轴和状态连续
→ 15：主动决定固定、连续运镜或CUT候选；定义动机、起点、路径、速度、终点和锁定
→ 14：验证SHOT或运镜阶段是否真的覆盖动作与画面证据
→ 13：仅对显式CUT决定CUT类型和相邻SHOT视觉差异
→ 01：封装SEG
```

## 采用结论

当前Skill不再只识别用户已经写出的运镜，而是要求在生成分镜前主动比较固定、运镜和CUT。新的决策层不会强制“能运就不切”；当观察任务改变、连续路径不可行、动作不可读、时长不足，或CUT具有明确冲击力与稳定性优势时，CUT仍然合法。
