# 项目进度诊断与解决闭环

## 诊断目标

先回答：

1. 用户真正完成到哪里？
2. 当前阻塞是什么？
3. 错误来自哪个上游真源？
4. 本轮交付什么才能直接推进？
5. 下一步有哪些不同路径？

不要把用户最后提到的现象自动当根因。视频里的错误可能来自剧本、空间图、资产、CUT、故事板、参考职责、提示词负载或模型执行。

## 证据优先级

1. 用户本轮明确修订和最新确认。
2. 用户标记为最终版、锁定版的文件。
3. 已确认的人物、服装、场景、道具、空间和声线资产。
4. 已通过审核的SHOT、CUT、故事板和提示词。
5. 已生成图片／视频中能观察到的事实。
6. 更早版本和模型自行生成内容。

冲突时采用更高优先级，并记录旧版本已作废。

## 阶段识别

| 现有材料 | 当前阶段 | 常见下一步 |
|---|---|---|
| 一句话、题材或灵感 | 灵感 | 故事核心和卖点 |
| 小说、故事或素材 | 改编 | 改编方案与分集 |
| 大纲或分集梗概 | 剧本 | 场景、动作和对白 |
| 完整剧本 | 分镜 | 空间确认、CUT与读秒 |
| 分镜表 | 分镜复审／资产 | CUT、空间、时长和资产检查 |
| 人物或场景卡 | 故事板 | 图片生成提示词 |
| 故事板图片 | 视频 | Seedance提示词 |
| 视频提示词但无法生成 | 视频故障 | 合规、SEG负载、引用和上游诊断 |
| 已生成图片或视频 | 质检 | 根因修复和返修版本 |
| 多段视频 | 后期 | 拼接、声音和成片检查 |

多个阶段并存时，标出最靠后的阶段和需要回溯的上游阶段。

## 问题分类

| 问题类型 | 典型现象 | 首要修复层 |
|---|---|---|
| 故事问题 | 动机弱、钩子不足、逻辑断裂 | 大纲／剧本 |
| 对白问题 | 漏台词、OS被角色听见、人物同声同气 | 剧本／声线 |
| SHOT任务问题 | 主体改变却没拍到关键动作、进出场无边界、视角标签无证据 | SHOT任务／动作覆盖规则 |
| SEG结构问题 | 把10秒编号等同连续SHOT、普通段碎切、高速动作被误判、固定机位时间流逝被拆散 | SEG类型／结构验证 |
| CUT问题 | 过载SHOT、无效快切、无意近似机位跳切、动作重复 | 动作链／CUT规则 |
| 空间问题 | 跳轴、瞬移、朝向错误、信息不可见 | 空间图／机位 |
| 资产问题 | 道具、服装、脸、场景错误 | 资产真源 |
| 生图问题 | 参考图混用、人物错误、版式错误 | 参考职责／生图提示词 |
| 视频执行问题 | 动作失控、角色重复、生成失败 | SEG负载／视频提示词 |
| 合规问题 | 提示词被拦截 | 最小合规改写 |
| 声音问题 | 漏字、含糊、被BGM遮盖 | 对白时长／收音 |
| 后期问题 | 重复帧、错误跳切、声音断裂 | 剪辑／状态衔接 |

“切镜频繁”不能直接判为错误。先区分：

- 当前SEG属于普通剧情、高速动作还是固定机位时间流逝。
- 合法CUT数量较多，但节奏需要重新分配。
- 格子被误当SHOT。
- 同一SHOT的推拉摇移、自然景别变化或焦段提示被误拆成SHOT。
- 角度、景别、主体和构图变化都不足，造成无意近似跳切。
- 有效CUT被错误合并成过载SHOT。

## 执行闭环

1. **盘点**：读取完整材料，列出已确认、冲突和缺失。
2. **定位**：找到主问题、真源和波及范围。
3. **决策**：选择最小但完整的修复；只有高影响分支才让用户选择。
4. **执行**：直接修改剧本、世界空间、SHOT任务合同、分镜、资产、提示词或文档。
5. **回归检查**：检查时长、SHOT任务覆盖、CUT、空间、资产、声音和后续状态。
6. **二次修正**：修掉自检错误再交付。
7. **推进**：报告完成度，并提供三个带Skill命令的下一步。

不要把未经修正的问题清单当最终交付。

## 波及检查

- 剧情修改：分集、大纲、对白、分镜、资产需求和钩子。
- 对白修改：说话人、口吻、时长、反应、OS／画外音、音频和口型。
- 人物／服装修改：资产卡、所有出场SHOT、故事板和视频提示词。
- 道具修改：资产、尺寸、表面、持物手、接触动作和跨镜状态。
- 场景修改：方向定义、拓扑、锚点、人物坐标、轴线和机位。
- 分镜修改：SEG类型、动作链、SHOT任务证据、连续运镜阶段、场景观察签名、CUT、前后状态、声音桥和总时长。
- 故事板修改：格序、SHOT归属、CUT标记和状态继承。
- 合规修改：确认没有误删剧情信息和张力。

## 完成度判定

- **已完成**：产物存在、范围完整并通过核心检查。
- **进行中**：已有部分内容，但仍有缺页、未确认或未修复问题。
- **未开始**：没有对应产物。
- **被阻塞**：存在关键资料缺失、设定冲突、工具失败或必须由用户决定的分支。
- **需返工**：已有产物，但错误会阻止后续生产。

分镜只有同时通过以下项目才算完成：

- 已确认或可唯一推导的世界空间。
- 每个SHOT的任务、动作覆盖、视角证据和状态机通过。
- SEG类型、显式SHOT／CUT计数和连续运镜阶段通过结构验证。
- 合法CUT和相邻SHOT视觉差异路径。
- 时长与对白容量。
- 人物、道具和动作状态继承。
- 信息可见性。

任一硬错误存在时只能标记“需返工”。

## 项目状态档案

跨多个阶段、多集、多版本或需回溯多个文件时，使用 `../assets/project-state-template.md`。

状态档案记录：

- 唯一真源版本。
- 分镜规格和SHOT规则。
- 场景方向、固定锚点和关系轴线。
- 已锁资产。
- 已通过交付物和证据。
- 需返工项、阻塞和下一里程碑。
- 三个带Skill调用命令的下一步。

生成过但未质检的内容不能标为完成。

## 下一步选择

每次回复结尾固定且只提供A、B、C三个可执行选项，恰好一个推荐。每个选项的可复制文本必须以Skill命令开头：

```markdown
### A（推荐）｜动作名称
**调用命令：** `使用 $ai-short-drama-director，选择A：动作名称。`
- 用户需要：
- Skill执行：
- 交付物：
- 推荐原因：

### B｜动作名称
**调用命令：** `使用 $ai-short-drama-director，选择B：动作名称。`
- 用户需要：
- Skill执行：
- 交付物：
- 适用情况：

### C｜动作名称
**调用命令：** `使用 $ai-short-drama-director，选择C：动作名称。`
- 用户需要：
- Skill执行：
- 交付物：
- 适用情况：
```

禁止只写“A”“回复A”或“选择B”。用户选定后直接利用现有上下文执行，不再次索要已经提供的材料。

## 新手模式路由

无法判断起点时展示：

```text
使用 $ai-short-drama-director，选择A：我只有灵感。
使用 $ai-short-drama-director，选择B：我有小说、故事、大纲或剧本。
使用 $ai-short-drama-director，选择C：我已有图片、分镜、提示词或视频，需要诊断。
```

信息足够时自动选择起点并执行，不先让用户填写长问卷。
