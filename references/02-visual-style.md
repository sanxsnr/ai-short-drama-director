## 风格锁定方法

把风格拆成六项并保持全剧一致：

1. 媒介：真人写实、3D动画、游戏CG、二维动画或特殊材质。
2. 年代地域：现代都市、民国北方、古代市井、未来废土等。
3. 材质：皮肤、发丝、布料、金属、建筑表面的物理表现。
4. 光线：主光方向、软硬、冷暖和暗部保留。
5. 色彩：主色、辅色、点缀色与饱和度。
6. 镜头质感：焦段、景深、颗粒、动态模糊和后期氛围。

先写一段“全局风格锁”，再分别浓缩为画图版和视频版。不要在每个镜头复读整段风格。

用户用知名作品、角色、明星或工作室举例时，提取其抽象属性，最终改写为原创描述，不保留模仿特定角色脸或特定在世创作者风格的要求。

## 五类基础风格

### 电影级真人写实

画图版：

```text
电影级真人写实主义，院线剧情片剧照质感，真实皮肤与服化道物理纹理，柔性立体布光，暗部保留五官细节，克制景深与自然色彩分级，高精度画面；避免CG塑料感、动漫感和过度磨皮。
```

视频版：

```text
电影级真人写实影像，真实材质与自然运动，柔光漫反射和侧逆光轮廓，暗部细节完整，镜头运动稳定，具有院线剧情片的光影层次。
```

### 高规格3D国风动画

画图版：

```text
高规格3D半写实国风动画，次世代电影级渲染，角色骨相适度动画化，肌肤温润干净，发丝呈有序块面层次，丝绸、皮革与金属材质区分明确，光线追踪与精细布料解算，史诗感与精致感并存。
```

视频版：

```text
次世代3D国风动画影像，角色表面干净统一，发丝和服饰具有稳定物理动态，材质边界明确，柔和体积光与轮廓光营造电影感。
```

### 次世代3A游戏CG

画图版：

```text
次世代3A游戏CG电影质感，高精度立体建模，通透但不过度油亮的次表面散射肌肤，真实PBR布料、刺绣与金属纹理，细致毛发动态，柔和全局照明、体积光、轮廓光和自然景深。
```

视频版：

```text
次世代游戏CG过场动画质感，真实PBR材质与稳定物理运动，柔和全局照明配合体积光和轮廓光，镜头具备高成本电影预告片质感。
```

### 高规格二维动画

画图版：

```text
高规格现代二维动画，纤细透气的色线描边，纯净赛璐璐上色，阴影边缘清楚且颜色通透，精细动画摄影后期，柔和泛光、环境反射与适量丁达尔光，避免粗黑线和廉价矢量感。
```

视频版：

```text
高规格二维动画影像，稳定纤细线稿与通透赛璐璐光影，动作关键帧清楚，环境反射、柔和泛光和空气透视统一。
```

### 彩塑泥人与物理微缩戏台

画图版：

```text
原创东方彩塑泥人定格动画质感，人物具有手工塑形的细微压痕、哑光颜料和稳定的雕塑五官，服装为真实微缩布料与手工缝制结构；场景采用可触摸的物理微缩戏台、木材、泥墙、纸窗和微型道具，冷暖灯光真实投射，具有镜头内实拍的景深与材料尺度感；避免真人演员感、二维插画感和光滑CG塑料感。
```

视频版：

```text
东方彩塑泥人定格动画与物理微缩戏台影像，保留手工塑形、微缩布料和真实材料尺度，动作具有稳定细腻的逐格表演感，灯光在实体布景中自然流动，避免真人化和光滑CG感。
```

## 彩铅安全转绘

仅在用户要求把现有画面转成彩铅时使用：

```text
严格继承参考图中的原创人物长相、五官比例、发型、服装款式、颜色、动作、画幅与基础构图，不裁切、不拉伸、不更换身份。只改变渲染媒介：转绘为高质量彩铅插画，线条细腻，色彩带自然颗粒和通透叠色，保留原有体积光影，降低真人照片感。
```

不要把彩铅描述成“绕过人脸审核”的工具。
