## 通用规则

- 先分清常驻资产与当前剧情状态。资产图和资产小结只写默认常驻状态。
- 根据角色身份、时代、地域、阶层和剧情功能设计，不给所有女性统一现代妆容。
- 每份资产同时描述视觉皮囊和物理骨架：宽松或紧身、是否遮脸、武器位置、长兵器或披风的碰撞体积。
- 角色、场景和道具小结控制在80—120个中文字符左右；以信息完整优先，不机械截断句子。
- 参考图有多张时，先列“来源图—唯一用途”，禁止一张版式图覆盖人物或场景资产。
- 资产提示词默认输出 XML 两段，不增加解释。
- 为长期项目分配稳定资产编号和版本，例如“CHAR-01_v03”“PROP-02_v02”。人物名字不代替资产版本。
- 已经锁定的资产是后续分镜、故事板和视频提示词的唯一真源；当前生成结果不能反向覆盖资产，除非用户明确确认改版。

## 核心角色

画图提示词必须以以下结构开头，并把三个细节框替换为具体内容：

```text
角色设定图（Character design sheet），横版16:9，网格化排版，纯白背景。右侧整齐排列同一原创角色的正面全身、侧面全身、背面全身；左侧上方为清晰正面大头面部特写；左侧下方并排三个小型局部特写框，分别展示：[细节1]、[细节2]、[细节3]。全局风格限定：[全局画风]。
```

正文必须覆盖：

1. 骨相与五官：脸型、眉眼、鼻唇、年龄感和气质。
2. 面部状态：身份相符的妆容、疤痕、疲态或洁净程度；不写临时情绪。
3. 发型发饰：长度、束发方式、材质和固定结构。
4. 服装材质：形制、层次、主辅色、布料、金属和鞋履。
5. 三个身份细节：写清形状、材质、佩戴或携带位置。
6. 一致性：三个全身角度与面部特写必须是同一个人、同一套常驻服装。

输出：

```xml
<画图提示词>
完整角色设定图提示词
</画图提示词>

<资产小结>
80—120字状态中立的角色视觉与物理设定
</资产小结>
```

## 群演群体

画图提示词以以下结构开头：

```text
横向宽幅构图，16:9，多名原创角色并排站立，非三视图，统一正面朝前站直，纯白背景。群体具有符合剧情的年龄、性别、身高、体型与面貌差异。全局风格限定：[全局画风]。
```

正文覆盖：

- 人员构成及比例。
- 同一阶层或阵营的共同气质，同时保证每张脸和体型不同。
- 服装共性、色调、材质及个体差异。
- 是否统一持长兵器、重盾、包裹或工具；说明空间占用和服装飘动。

沿用角色资产的 XML 输出格式；小结明确这是“群演”。

## 六格场景

先在内部建立东南西北坐标和三个不可移动锚点。画面描述使用“2D画面位置＋括号内3D物理方位”，例如“画面左侧（东面）”。

提示词必须以以下结构开头：

```text
A highly professional strictly 6-panel scene concept board. Top half: exactly 2 large wide panels side by side. Bottom half: exactly 4 smaller panels side by side. Total exactly 6 panels, no more, no less. Each panel has only one short label in its top corner; no paragraphs or instruction text inside the image. Clean 16:9 layout. 全局画风限定：[全局画风]。
```

依次填写：

- G01“主场景·XX”：正向全景，明确2D位置和3D方位。
- G02“反向·XX”：严格按同一坐标系旋转180度，重新计算左右。
- G03“局部·XX”：建筑细节与真实角落，不做白底孤立物。
- G04“道具·XX”：道具放在所属环境中。
- G05“俯视图”：只用东南西北写绝对位置，与G01/G02一致。
- G06“色板”：整齐纯色色块。

每个 XX 使用2—4个汉字。若生成模型文字不稳定，保留 G01—G06 编码，删除额外中文标签。

场景小结必须包含建筑风格、默认光影、空间开阔度、三个固定锚点和不可跨越障碍。

## 道具资产

道具资产写清：

- 尺寸、材质、颜色、磨损和开合结构。
- 日常放置或佩戴位置。
- 是否需要双手操作、是否遮挡身体、是否产生碰撞体积。
- 不把当前破损、燃烧或血污状态写成默认状态，除非这是道具永久属性。

输出：

```xml
<画图提示词>
16:9专业道具资产卡。写清主视图、正侧背或结构视图、局部细节、尺寸比例、材质色板、开合／使用状态和与人体的比例参照。禁止加入不属于项目时代和场景的无关物品。
</画图提示词>

<资产小结>
编号、名称、尺寸、材质、颜色、固定结构、日常位置、操作方式、碰撞体积和不可改变特征。
</资产小结>
```

## 声线资产

写清：

- 年龄与性别听感、音域、音色、共鸣位置、语速和吐字。
- 不用“像某明星”定位。
- 写清对白可懂度、音量、距离感和收音方式；具体风格服从剧情和用户要求。

输出状态中立的声线卡：

```text
角色／声线编号：
年龄与性别听感：
音域与音色：
共鸣位置：
正常语速：
吐字与句尾习惯：
不同情绪下允许的变化：
固定收音：写明近讲／远距、清晰度、空间混响和与环境声的关系。
禁止：模仿真人明星；除非剧情明确要求，不让环境声遮盖关键信息。
```

## 资产纠错与全局回写

发现人物、服装、场景或道具错误时：

1. 对照剧情、用户最新确认和锁定资产，确定正确版本。
2. 修改资产提示词和资产小结，递增版本号。
3. 搜索整个项目中旧名称、旧颜色、旧尺寸、旧持法和错误出场位置。
4. 更新受影响的分镜脚本、故事板生图提示词、首尾帧和视频提示词。
5. 检查修改前一段与后一段是否仍连续。
6. 交付完整修订文档，列出被替换的旧设定和新真源。

道具错误重点检查：

- 是否在剧情需要前提前出现。
- 是否突然消失或凭空出现。
- 尺寸是否适合角色携带和场景空间。
- 是否换手、穿模或改变开合状态。
- 是否被版式参考图中的无关物品替换。

人物或服装错误重点检查：

- 脸型、年龄、发型和身份气质。
- 当前镜头是否穿了不属于该阶段的服装。
- 污渍、雨水、伤痕等临时状态是否被误写成长期资产。
- 多张参考图是否发生身份混用。
