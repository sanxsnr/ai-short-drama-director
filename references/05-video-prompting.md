## 唯一目标平台

本Skill所有“生成视频提示词”任务统一输出 **即梦 Seedance 2.0** 格式，不再提供或并列输出其他视频模型格式。

禁止在视频提示词、标题、说明或下一步选项中出现：

- I2V、FLF2V、WAN、VACE或“通用视频模型版本”。
- “首帧引用”“尾帧引用”“首帧—尾帧”“END FRAME”。
- CUT、TAIL、入场画面衔接、出场画面衔接等内部制片字段。
- `Asset_Setup`、XML、十字段镜头表、自检日志或透明代理指令。
- “请选择生成模式”或让用户再次选择视频模型。

分镜和项目内部仍可维护动作开始状态、结束状态与跨镜连续性，但这些内部信息必须翻译成自然动作顺序，不能原样泄漏到Seedance 2.0生产提示词。

## 两层架构

内部导演计划用于检查：

- 当前10秒或15秒镜头的剧情、人物、场景、道具和动作顺序。
- 人物左右、运动方向、持物手、空间锚点和连续性。
- 运镜、对白、声音、光线和结束停点是否可实现。
- 实际上传了哪些图片、视频和音频，每个素材负责什么。

面向用户交付时只输出：

1. 一段干净、可复制的Seedance 2.0提示词代码块。
2. 代码块外的简短进度、自检与下一步选择。

用户明确只要提示词时，不展示内部导演计划、素材分析过程和字段表。

## Seedance 2.0素材引用

Seedance 2.0使用界面中的 `@` 引用素材。只引用用户实际准备上传的素材，严格按上传顺序编号：

```text
@图片1
@图片2
@视频1
@音频1
```

禁止写成文件名、资产编号、`@参考图1`或不存在的附件编号。每个引用必须在同一句中写明唯一职责：

```text
参考@图片1中“阿绣”的人物长相、发型和服装。
场景结构与默认光影参考@图片2。
参考@图片3中木盒的外观、尺寸和材质。
动作节奏与摄影机移动参考@视频1，不继承其中人物和场景。
角色声线参考@音频1。
```

允许的素材职责：

- 人物长相、发型、服装和当前状态。
- 场景结构、陈设、空间关系和光影。
- 道具外观、尺寸、材质和使用方式。
- 故事板中的动作顺序、构图、人物调度和运镜逻辑。
- 参考视频的动作轨迹、摄影机运动、节奏或特效。
- 参考音频的声线、音效、节奏或背景音乐。

同一素材不得承担冲突职责。没有上传某类素材时，不虚构对应的 `@` 编号。

## 固定输出格式

每个视频镜头最终只能交付以下结构，不得改成表格、XML、镜头卡或其他模型格式：

````markdown
## Seedance 2.0提示词

```text
[按上传顺序写清@图片、@视频、@音频的唯一职责。]

生成一段[10秒／15秒]的[题材与风格]视频。场景为[场景]，[人物名字与可识别外观]位于[位置]，[另一人物]位于[位置]。

0—[X]秒：[动作、表演、运镜和构图。]
[X]—[Y]秒：[动作连续发展、对白和反应。]
[Y]—[总时长]秒：[动作完成、摄影机变化和自然收束。]

对白：[人物名字]（语气）：“完整台词。”[没有对白则写“无对白”。]
声音：[环境声、关键音效、音乐或声线要求。]
画面：[全局风格、光线、材质、色调和必要画质要求。]
要求：[只写本镜最容易失败的具体约束。]
```
````

固定规则：

- 代码块第一句直接分配 `@` 引用职责，没有素材则直接从“生成一段……”开始。
- 视频时长只使用分镜已经锁定的10秒或15秒，不重新询问其他模式。
- 时间段首尾连续，总时长准确；动作少时可使用自然段，不为了凑格式机械拆成三段。
- 最后一段写动作如何完成和画面如何自然收束，不使用“尾帧”“结束帧”术语。
- 提示词代码块内不得出现标题、镜头编号、制作进度、解释、选项或自检。
- 不额外输出“通用版”“I2V版”“FLF2V版”或其他备选格式。

## 短剧提示词模板

复制并填写 `assets/seedance2-prompt-template.md`。生产提示词使用自然语言，可直接粘贴：

```text
参考@图片1中“阿绣”的人物长相、发型与服装；参考@图片2中“陈九”的人物长相、发型与服装；场景结构和光影参考@图片3；参考@图片4九宫格从左上到右下的动作顺序、人物调度和运镜逻辑，九格属于同一连续镜头，不代表九次切镜。

生成一段10秒的民俗悬疑短剧视频。阿绣站在画面右侧桌边，陈九从画面左后方进入，两人的左右关系和场景结构保持稳定。

0—3秒：中景平视，镜头缓慢跟随陈九向桌边走近；阿绣闻声转头，手仍停在桌面。
3—7秒：镜头轻微推近，陈九停在桌前，与阿绣保持一步距离，视线落在桌上的木盒；阿绣把手收回，身体重心后移。
7—10秒：镜头横移形成双人侧面构图，陈九抬眼看向阿绣，阿绣保持警觉，两人动作自然停稳。

对白：陈九（克制）：“这东西，你从哪儿找到的？”
声音：室内轻微风声、脚步声、衣料摩擦声和木桌轻响；对白清楚可辨，人物开口时环境声适度降低。
画面：电影级民俗悬疑质感，真实布料和木质材质，柔和侧光，暗部保留五官细节，冷灰色调。
要求：仅出现阿绣和陈九；不得换脸、换装、互换左右或增加人物；木盒始终位于桌面，不得消失、变形或换位；禁止字幕、水印和无关文字。
```

示例中的人物、剧情、声音和风格只展示格式，不得成为其他项目的默认设定。

## 动作、运镜与时间

- 先按真实先后写动作，避免同时堆叠多个互相竞争的事件。
- 10秒或15秒内容可以按时间段描述；同一连续运镜不因故事板有九格而切成九段。
- 运镜只写当前镜头真正需要的一到两个主运动，例如“跟拍后轻推”，避免固定、环绕、快速摇镜同时出现。
- 角色移动写清起点、路径和终点；物理接触写清执行者、接触对象、方向和动作结果。
- 动作必须在时长内完成。不能完成时回到分镜重新切分，不用“快速完成”掩盖超载。
- 画面结尾只描述可见的完成状态或自然停顿，不使用首帧、尾帧、TAIL或END FRAME字段。

## 对白与声音

- 完整保留源剧本已经确认的说话人、台词和顺序，不擅自增加旁白。
- 正常中文语速按每秒约4—5字检查；停顿、抢话、喘息和反应时间另计。
- 写清人物名字、语气和完整台词，不能只写“角色A”。
- 声线素材使用 `@音频1`，明确只参考音色、语速或语气。
- 环境声、动作音效和音乐服从剧情；关键信息必须可辨认。
- 声音指令写在同一Seedance提示词内，不另交付其他声音模型格式。

## 故事板引用

使用GPT专业九宫格或Gemini简化九宫格作为Seedance参考时：

```text
参考@图片4九宫格从左上到右下的动作顺序、构图、人物调度和运镜逻辑；九格属于同一个连续镜头，不代表九次切镜。人物长相、服装和场景分别以@图片1、@图片2、@图片3为准。
```

不得写：

```text
@图片4作为首帧。
@图片5作为尾帧。
按首帧—尾帧生成。
```

其他生图工具提供站位俯视图和正面站位图时，只把它们用于人物位置、朝向、距离、轴线和构图，不要求Seedance把俯视示意图直接演绎为成片画面。

## 输入包与差异闸门

生成提示词前读取 `references/09-generation-session-control.md`，当前镜头默认只装入：

- 当前镜头源剧本和已锁定10秒／15秒时长。
- 当前出场人物、服装、声线和临时物理状态。
- 场景结构、人物站位、关键道具和动作开始／完成状态。
- 实际准备上传的图片、视频、音频及其唯一职责。
- 精简全局风格。

输出后逐项比较：

- 每句台词、说话人和顺序是否正确。
- 每个动作和结果是否保留。
- 人物、服装、场景、道具是否来自正确资产。
- `@`编号是否与实际上传顺序一致，每个素材是否都有唯一职责。
- 是否新增未授权人物、动作、对白、道具或场景。
- 是否泄漏其他模型名、首尾帧术语或内部制片字段。

## 生成失败与修订

### 无法提交

- 检查写实真人素材、受保护角色、品牌、色情、明确血腥和高风险措辞。
- 进行最小合规改写，保留事件因果，不承诺保证通过。

### 能提交但不执行

- 检查人物、动作、场景或 `@`引用是否过多。
- 检查故事板、人物图、场景图是否互相争夺职责。
- 减少本镜输入，只保留当前事件需要的素材。
- 把技术字段改成按时间推进的自然语言。

### 能生成但结果错误

- 人物错误：回查人物名字、角色图职责和服装状态。
- 站位错误：回查站位图、人物左右、起点和运动方向。
- 道具错误：回查道具图、尺寸、持物手和出现时机。
- 动作错误：减少并行动作，明确动作完成点。
- 声音错误：检查说话人、台词长度、语气和混音要求。

修订时交付完整Seedance 2.0提示词，不只发送追加句；同步修复上游资产、分镜或故事板中的同源错误。

## 输出前硬性检查

- [ ] 只输出Seedance 2.0格式，没有其他视频模型版本。
- [ ] 生产提示词是单个自然语言代码块，没有XML、表格或镜头卡。
- [ ] 没有I2V、FLF2V、WAN、VACE、首帧、尾帧、TAIL、CUT或END FRAME。
- [ ] 所有 `@图片／@视频／@音频` 都对应实际素材且职责唯一。
- [ ] 时长只使用已锁定的10秒或15秒。
- [ ] 人物使用名字，动作按时间推进，运镜无冲突。
- [ ] 原对白完整，声音要求可实现。
- [ ] 没有新增未授权剧情、人物、道具或场景。
- [ ] 代码块外的下一步选项不再让用户选择视频格式或首尾帧模式。
