# 质检、修复、声音与后期

## 适用范围

质检涉及切镜、机位、空间或连续性时，必须同时读取：

- `04-blocking-continuity.md`
- `14-shot-task-action-coverage.md`
- `13-cut-shot-geometry.md`

“切镜多”本身不是错误；只有无动机CUT、无意近似机位跳切、近似构图、动作重复、越轴或节奏无法实现时才判定为切镜问题。相邻景别本身不自动构成错误。

## 提示词质检

按顺序核对：

1. 原剧情、动作和对白是否完整且无擅自续写。
2. SEG总时长、SHOT时间码和对白容量是否可实现。
3. 每个SHOT是否真正完成task_type要求的画面证据，人物进出、视线揭示、接触和动作结果是否可见。
4. 所有自然CUT点是否保留，CUT类型是否正确。
5. 是否存在角度、景别、主体和构图差异都不足的无意近似跳切。
6. 人物、服装、场景、道具和声线是否来自锁定资产。
7. 空间方向、人物位置、轴线侧、视线和运动方向是否一致。
8. 起始状态、结束状态、持物手、门窗、污渍、战损和光线是否继承。
9. 当前景别、光线、遮挡和焦点是否真的能展示关键信息。
10. 参考图是否各司其职。
11. 最终视频提示词是否去掉内部说明、ABC导航和Skill命令。
12. 声音是否清楚，OS、画外音和实际对白是否区分。

## 生成结果质检

观看视频或关键帧时记录“问题—原因—真源—完整修复”：

- 角色脸、年龄、发型、服装是否漂移。
- 多人是否重复、消失或从错误方位出现。
- 手指、持物手、接触动作和身体比例是否稳定。
- 场景结构、门窗、家具和固定锚点是否被重建。
- scene_id／zone_id／anchor_id是否被自然语言近义词伪造为变化。
- 人物进出场时，边界、跨越路径和落点是否真实可见。
- POV／OTS／INSERT是否有真实几何证据，而不是只改了标签。
- 人物是否跳轴、瞬移、穿过障碍或无理由面向镜头。
- 动作是否完成，下一SHOT是否重复已经完成的动作。
- CUT是否丢失、误切或切成无意近似机位跳切。
- 关键细节是否因景别、逆光、遮挡或虚焦而不可见。
- 台词是否漏字、串角色、过快或被环境声遮盖。
- 唇形、音效、冲击和剪辑点是否同步。

最终必须输出修订后的完整产物；不能只列问题。

## 修复层级

### 1. 真源修复

先修造成错误的最上游文件：剧本、空间图、SHOT任务合同、资产、CUT或参考职责。

### 2. SEG负载修复

目标模型无法稳定完成时，可以：

- 将已经确认的SHOT拆到更多SEG。
- 减少同一SEG内的并行动作、人物或参考素材。
- 简化提示词技术术语。

不得为了降低负载删除、吞并或改写已经通过审核的有效CUT。

### 3. 无效CUT修复

只有下列情况才删除或合并CUT：

- 下一SHOT未通过`14`，`derived_independent_task=false`。
- 前后缺乏合法视觉差异路径，只形成无意近似跳切。
- 动作、视线和信息没有变化。
- CUT导致动作重演、越轴或状态重置。
- 格子或时间轴被误当成镜头数量。

有效CUT即使数量较多也必须保留。节奏过快时优先延长SHOT、重分配SEG或调整对白，不把有效CUT直接并回长镜头。

## 合规与原创改写

不承诺保证过审，也不研究绕过审核。按实际内容最小改写：

- 真人明星、受保护角色、品牌标志：改成原创人物与可视化特征。
- 性化视角、走光风险、透明衣料：改为合理机位、完整遮盖和不透明材质。
- 明确血腥细节：改为非图形化冲击、反应、声效或画外结果。
- 直接模仿受保护作品或在世创作者：转译为媒介、线条、色彩、光线和材质。
- 普通冲突、对峙或非血腥动作：保留合理张力。

输出完整修改版并附简短改动日志。

## 声音和剪辑

出现音色漂移、逐句换音、重复开头、声音桥、补帧或复杂拼接时，读取 `10-voice-editing-repair.md`。

声音统一：

- 为主要角色保存状态中立的声线小结。
- 统一对白音量、清晰度、距离感和收音方式。
- 同一场景保持响度、音色和空间混响稳定。
- 对白期间按用户要求让环境声与配乐让位。
- 补充脚步、衣料、道具、门窗和环境底噪，不盖住台词。

段落拼接：

- 比较上一SEG结束状态和下一SEG起始状态。
- 删除生成阶段产生的重复静帧、重复动作和重复台词。
- 保持运动方向、视线、动作速度和环境声连续。
- 按已经确认的CUT选择硬切、声音桥或必要转场，不叠加无意义效果。
- 不要求下一SEG保持上一SEG同一机位，也不默认复制尾帧。
- 只有用户明确使用I2V、FLF2V或视频延长时，才按该模式检查具体首尾帧。

## 全片巡检

所有片段完成后至少通篇检查一次：

1. 按剧本顺序播放。
2. 检查同一人物的脸、服装、声线和临时状态。
3. 检查家具、门窗、道具、锚点和人物相对位置。
4. 检查新增、遗漏、串角色或被改写的台词。
5. 检查相邻SHOT和SEG是否重复、跳帧、反向、断声或场景误变。
6. 检查所有CUT的动机、机位差异和连续性。
7. 检查物理接触是否落在正确目标和位置。
8. 记录每个问题的版本和上游根因，再做局部返修。

已通过片段不因其他片段出错而全部重做；修改片段必须复查前后至少各一段。

## 问题回溯

```text
可见问题：
直接原因：
上游根因：
需要修改的文件／段落：
已经执行的修改：
回归检查：
```

常见回溯：

- 道具错误：道具资产 → 人物持法 → 空间状态 → 分镜 → 故事板 → 视频提示词。
- 人物错误：人物资产／参考职责 → 出场SHOT → 视频。
- SHOT任务错误：04世界空间 → 14动作覆盖／场景观察签名 → 13 CUT → 下游提示词。
- 空间错误：场景锚点 → 人物坐标 → 轴线 → 摄影机 → 下游提示词。
- CUT错误：动作链 → CUT点 → 机位几何 → 状态继承 → SEG封装。
- 切镜观感过碎：先判断是否为无效CUT；只删除无效CUT，保留有独立叙事任务的CUT。
- 台词缺失：恢复说话人、台词、反应和时长。
- 视频不能生成：区分合规、SEG负载、引用冲突和平台参数。

## 最终自检

- 剧情因果和对白完整。
- 时长、SHOT和动作可实现。
- 每个SHOT的任务证据、进出场边界、视角证据和动作状态机正确。
- CUT点、类型和相邻SHOT视觉差异路径正确。
- 人物、服装、场景、道具和声线一致。
- 站位、轴线、视线、持物手和跨镜状态连续。
- 当前机位能展示所写信息。
- 参考图职责不冲突。
- 最终提示词干净、可复制且没有内部说明。
- 修复没有破坏后续剧情和锁定资产。

任一硬错误存在时只能判定“需返工”，不能用总体方向正确代替通过。
