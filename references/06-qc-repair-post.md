## 提示词质检

按顺序核对：

1. 原剧情、动作和对白是否完整且无擅自续写。
2. 单段总时长、镜头时间码和对白容量是否可实现。
3. 角色、服装、场景、道具和声线是否来自锁定资产。
4. 参考图是否各司其职。
5. 左右站位、180度轴线、专属背景和移动方向是否一致。
6. 首尾帧、持物手、门窗开合、污渍、战损和光线是否继承。
7. 最终视频提示词是否已去掉内部说明和无用参数。
8. 声音是否明确为清晰前景对白，环境声是否让位。

## 生成结果质检

观看视频或关键帧时，按以下顺序记录“问题—可能原因—最小修改”：

- 角色脸、年龄、发型、服装是否漂移。
- 多人是否重复、消失或从错误方位出现。
- 手指、持物手、接触动作和身体比例是否稳定。
- 场景结构、门窗、家具和主要锚点是否被重建。
- 人物是否跳轴、瞬移或穿过障碍。
- 动作是否完成，结尾是否停在下一段需要的状态。
- 台词是否漏字、串角色、语速过快或被环境声遮盖。
- 唇形、音效、动作冲击和剪辑点是否同步。

只修改导致问题的字段，不把整段全部推倒重写；但最终必须输出修订后的完整产物。

## 最小修复

采用三层修复：

1. 锁定修复：加强单一资产、位置、持物手、首帧或尾帧。
2. 简化修复：减少同段人物、动作、镜头或技术术语。
3. 拆段修复：只有在模型确实无法稳定完成时，才沿完整动作边界拆段。

如果模型“听不懂”，优先把提示词改成按时间顺序的自然语言，不使用代理身份、注入式命令或重复警告。

## 合规与原创改写

不要承诺“保证过审”，也不要研究或描述绕过审核的方法。按实际内容做最小范围的安全改写：

- 真实明星、受保护角色、品牌标志：换成原创人物和可视化特征。
- 性化视角、走光风险、透明衣料：改成平视或合理机位、完整遮盖和不透明材质。
- 明确血腥细节：改成非图形化冲击、人物反应、声效或画外结果。
- 针对受保护作品或创作者的直接风格模仿：转译为媒介、线条、色彩、光线和材质属性。
- 普通剧情冲突、对峙或非血腥动作：保留合理戏剧张力，不做无关删改。

输出完整修改版，不省略未修改部分；另列简短改动日志。

## 声音和剪辑

出现音色漂移、逐句换音、重复开头、声音桥、补帧或复杂拼接时，完整读取 `references/10-voice-editing-repair.md`。

声音统一：

- 为每个主要角色保存状态中立的声线小结。
- 根据剧情和声场统一对白音量、清晰度、距离感和收音方式。
- 统一响度、音色和空间混响；同一场景不要忽远忽近。
- 对白期间压低环境声与配乐，停顿后再自然回升。
- 单独补充脚步、衣料、道具、门窗和环境底噪，不让音效盖住台词。

段落拼接：

- 比较上一段末0.5秒和下一段首0.5秒，删除重复静帧或重复动作。
- 保持运动方向、视线、动作速度和环境声连续。
- 对硬切、叠化和声音桥只选一种最符合剧情的衔接，不堆叠效果。
- 把口型校正放在对白与画面确定之后。
- 最终检查字幕、画幅、帧率、响度和导出清晰度。

输出修复建议时优先给可直接替换的提示词片段，再给原因。

## 全片巡检

单段通过不代表整集通过。所有片段完成后至少执行一次通篇检查：

1. 按剧本顺序播放，不跳过看似正常的片段。
2. 检查同一人物的脸、服装、声线和临时状态是否跨段漂移。
3. 检查家具、门窗、道具、背景锚点和人物相对位置是否逐段改变。
4. 检查新增、遗漏、串角色或被模型改写的台词。
5. 检查相邻片段是否重复、跳帧、运动反向、声音断裂或场景瞬变。
6. 检查物理接触是否落在正确目标和位置。
7. 记录每个问题对应的片段、版本和上游根因，再做局部返修。

已通过的片段不因其他片段出错而全部重做。修改后的片段必须重新检查前后至少各一段，并在生成尝试记录中标明最终采用版本。

## 问题回溯与交付

质检不是只打分。对每个问题记录：

```text
可见问题：
直接原因：
上游根因：
需要修改的文件／段落：
已经执行的修改：
回归检查：
```

需要正式交付时使用 `assets/repair-report-template.md`，把问题、根因、实际修改、影响范围和回归结果写完整。

常见回溯：

- 道具错误：道具资产 → 人物持法 → 分镜 → 故事板 → 视频提示词。
- 人物错误：人物资产／参考图职责 → 出场镜头 → 首尾帧 → 视频。
- 分镜逻辑不清：事件因果 → 起始状态 → 动作阶段 → 结束停点 → 下一段承接。
- 切镜频繁：判断格子是否被误当切镜；合并同方向动作，改为连续跟拍或一镜到底。
- 台词缺失：恢复说话人、台词、反应和时长；重新检查声音。
- 视频不能生成：区分合规、模型负载、引用冲突和平台参数，不把所有失败都归因于审核。

用户提供文档时，把修复写回完整文档并执行全局搜索，确保旧错误没有残留。用户只提供单段提示词时，输出该段完整修订版。

最终自检至少覆盖：

- 剧情因果和对白完整。
- 时长与动作可实现。
- 人物、服装、场景、道具和声线一致。
- 站位、轴线、持物手、首尾帧和跨段状态连续。
- 参考图职责不冲突。
- 最终提示词干净、可复制且没有内部说明。
- 修复没有破坏后续剧情和既有锁定资产。
