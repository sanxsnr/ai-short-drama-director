## 使用目标

把“模型不听话”拆成可以定位的具体问题。不要只继续加长提示词。优先判断：

- 源剧本是否清楚。
- 当前段是否超出模型负载。
- 输入包是否混入无关段落或旧版本。
- 参考图是否比文字更强地传递了错误人物、场景或站位。
- 提示词是否新增、遗漏或改变了源内容。
- 多次生成是否有可比较的版本记录。

## 最小输入包

每次只给当前任务真正需要的材料。

视频段落默认输入包：

```text
任务编号与目标平台：Seedance 2.0
目标时长与画幅：
当前段源剧本：
本镜动作开始状态：
本镜动作完成状态：
精简全局风格：
本段人物／服装／声线简述：
本段场景拓扑与固定锚点：
关键道具、尺寸、持物手和状态：
实际上传图片／视频／音频及其Seedance `@`编号和唯一职责：
禁止新增或改变的内容：
```

默认只装入当前1—2个制片段。只有当前剧情必须依赖更早信息时，才增加一句必要背景，不整集复制。

长版资产提示词用于生成和修改资产；视频输入包使用80—120字资产小结或更短识别特征，不重复完整设计文档。

## 上下文预算

按优先级保留：

1. 用户本轮最新确认。
2. 当前真源剧本和当前段原文。
3. 锁定资产及当前物理状态。
4. 当前动作开始状态和完成状态。
5. Seedance 2.0时长与画幅。
6. 只与本段有关的风格和参考素材。

优先删除：

- 已作废版本。
- 失败候选的完整提示词。
- 不在本段出场的人物资产。
- 只用于版式、但正文已经确定的重复说明。
- 同义反复的警告和大量泛化负面词。
- 与当前平台无关的参数。

当输入仍过长时，先压缩说明，不删除源台词、锁定资产、持物手、动作开始／完成状态和参考职责。

## 参考素材优先级

参考素材必须写唯一职责：

```text
@图片1：只锁人物脸、发型和固定服装。
@图片2：只锁无人场景结构、陈设和光影。
@图片3：只锁道具外观、尺寸和开合结构。
@图片4：只参考故事板的动作顺序、构图、调度和运镜逻辑。
@视频1：只参考动作轨迹或摄影机运动。
@音频1：只参考已授权的角色声线。
```

优先使用干净裁图，不让一张大设计板同时承担锁脸、锁全身、锁道具和锁场景。

## 参考冲突排查

当文字正确但输出持续错误时，按顺序检查：

1. 错误是否已经存在于人物、场景、故事板或站位参考图。
2. 场景参考是否带有不应出现的人物或道具。
3. 角色设计板是否包含多个角度，被模型误当成多人。
4. 版式参考是否把示例人物、服装或场景带入当前画面。
5. 多张参考图是否给同一人物不同服装、年龄或发型。
6. 作废提示词、旧资产或失败参考是否仍留在当前会话。
7. 当前文字是否要求模型同时服从互相冲突的职责。

发现冲突时，替换错误参考、裁出任务专用图或减少引用数量。不要保留强烈错误图，再用大量否定词要求模型忽略。

## 干净会话重置

出现以下任一情况时建立新会话或清空当前任务上下文：

- 同一段反复修改三次以上，模型仍复现旧错误。
- 已上传多个作废人物、站位或场景版本。
- 模型持续生成已删除的台词、人物、家具或动作。
- 当前输出明显混合前后两段内容。
- 引用职责已无法从会话历史中分清。

重置步骤：

1. 保存当前真源和失败原因，不复制整段旧对话。
2. 新会话只放当前最小输入包。
3. 重新列参考素材唯一职责。
4. 只提交当前段生产版提示词。
5. 生成后按同一验收表比较，不因画面华丽放过剧情错误。

## 原文差异闸门

提示词输出后，与源剧本逐项核对：

- 每句台词、说话人和顺序。
- 每个可见动作及结果。
- 出场人物和入画时机。
- 场景、服装和关键道具。
- 当前段起始状态和结束停点。
- 环境声和关键音效。

分类处理：

- **完全继承**：可进入生产版。
- **为了可视化而补足**：不改变剧情，可保留并注明。
- **可选创作建议**：单列给用户选择，不进入生产版。
- **未授权漂移**：删除并重新检查时长和连续性。

结构化输入包使用 `scripts/validate_prompt_package.py` 检查缺项、台词遗漏、引用冲突和内部标记泄漏。脚本不能识别所有语义改写，仍需人工通读。

## 多次生成与停止条件

同一提示词默认先生成2—4个可比较候选，具体数量服从成本、平台限制和用户要求，不使用固定“通过率”。

使用 `../assets/generation-attempt-log.md` 记录：

- 尝试编号、提示词版本和生成参数。
- 实际使用的参考素材。
- 剧情、资产、空间、动作、声音和衔接结果。
- 失败原因、修改点和是否采用。

停止条件：

- 剧情与对白正确。
- 核心资产和物理关系正确。
- 动作完整且结束停点可承接。
- 声音可用或已有明确后期修复方案。
- 没有会阻止下一阶段的错误。

候选画面再漂亮，只要改变剧情、人物身份、空间或关键道具，就不能因为“效果好”直接采用。

## Seedance 2.0固定适配

视频生产提示词只输出Seedance 2.0格式：

- 使用 `@图片1`、`@视频1`、`@音频1` 指定实际上传素材的唯一职责。
- 使用自然语言按时间推进动作、运镜、对白、声音和画面风格。
- 内部导演字段只用于检查，不进入生产提示词代码块。
- 不生成I2V、FLF2V、WAN、VACE、通用模型或其他平台版本。
- 不输出首帧、尾帧、CUT、TAIL、END FRAME或生成模式选择。
- 需要继续已有视频内容时，仍按Seedance 2.0的 `@视频1` 引用语法描述新动作，不另建其他格式。

平台额度和经验成功率可能变化，只作为当次项目记录，不写成永久规则。

## 交付与验收

交付当前段时包含：

1. 干净可复制的Seedance 2.0生产版提示词。
2. 输入包摘要和 `@`参考职责映射。
3. 原文差异检查结果。
4. 已采用候选和未采用原因。
5. 下一镜需要继承的人物、道具、空间与动作完成状态。

用户只要提示词时，先给生产版；其他记录放在代码块外并保持简短。
