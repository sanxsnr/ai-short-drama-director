# 生成会话、输入包与版本控制

## 适用范围与优先级

本文件负责把已经确认的剧本、空间、SHOT任务合同和CUT组装成最小生成输入包，不负责重新划分镜头。

涉及视频或故事板中的机位变化时，同时读取：

- `04-blocking-continuity.md`
- `14-shot-task-action-coverage.md`
- `13-cut-shot-geometry.md`

输入包压缩、平台限制或模型负载不能删除已经通过审核的CUT。模型无法承载时，应拆分SEG，而不是合并合法SHOT。

## 使用目标

把“模型不听话”拆成可定位的问题：

- 源剧本是否清楚。
- 空间、人物和道具状态是否唯一。
- SHOT任务证据、动作覆盖、CUT和时间码是否已经通过审核。
- 当前SEG是否超出模型负载。
- 输入包是否混入旧版本或无关段落。
- 参考图是否比文字更强地传递了错误人物、场景或站位。
- 提示词是否新增、遗漏或改变源内容。
- 多次生成是否有可比较记录。

## 最小输入包

视频SEG默认输入包：

```text
任务编号与目标平台：
目标时长、画幅和生成模式：
当前SEG源剧本：
当前SEG的directorial_camera_plan：SHOT顺序、轨迹意图、CUT意图：
当前SEG包含的SHOT task_type、必要证据、状态转换与CUT审核：
上一SHOT／上一SEG结束状态：
本SEG起始状态：
本SEG目标结束状态：
下一SEG需要继承的状态：
精简全局风格：
本段人物／服装／声线简述：
已确认scene_space_basis、spatial_solution、scene_id／time_id、camera_zone_id、camera_position_world、camera_forward_world、固定anchor_id和摄影机轴线侧：
关键道具、表面、持物手和状态：
参考图／视频／音频唯一职责：
禁止新增、删除或改变的内容：
```

状态包括人物位置、朝向、视线、动作结果、道具归属、门窗、光线和剧情结果。状态继承不等于复制上一段最后画面或保持同一机位。

默认只装入当前1—2个SEG。只有当前事件依赖更早信息时，才增加一句必要背景，不整集复制。

## 上下文预算

按优先级保留：

1. 用户本轮最新确认。
2. 当前真源剧本和锁定对白。
3. 已确认15导演镜头方案、04空间解、SHOT任务合同、CUT和跨镜状态。
4. 锁定资产及当前物理状态。
5. 当前平台规格和生成模式。
6. 只与本段有关的风格和参考素材。

优先删除：

- 已作废版本。
- 失败候选的完整提示词。
- 不在本段出场的人物资产。
- 重复版式说明。
- 同义警告和泛化负面词。
- 与当前平台无关的参数。

输入仍过长时，先压缩说明，不删除源台词、SHOT必要画面证据、合法CUT、空间锚点、持物手、跨镜状态和参考职责。

## 参考素材优先级

参考素材必须写唯一职责：

```text
REF-CHAR：只锁脸、发型和固定服装。
REF-SCENE：只锁无人场景结构、陈设和光影。
REF-PROP：只锁道具外观、尺寸和开合结构。
REF-BLOCK：只锁已验证的人数、位置、朝向和轴线。
REF-MOTION：只参考动作轨迹或运镜。
REF-VOICE：只参考已授权角色声线。
```

只有用户明确选择对应工作流时才加入：

```text
REF-FIRST：仅用于I2V、视频延长或用户明确指定的首帧。
REF-LAST：仅用于FLF2V或用户明确指定的目标尾帧。
```

普通Seedance多镜头流程不默认需要REF-FIRST或REF-LAST，也不要求后一SEG复制前一SEG最后画面。

## 参考冲突排查

文字正确但输出持续错误时检查：

1. 错误是否已存在于空间图、首帧或参考素材。
2. 场景参考是否带有不应出现的人物或道具。
3. 角色板是否包含多个角度，被误识别为多人。
4. 版式参考是否带入示例人物、服装或场景。
5. 多张参考是否给同一人物不同服装、年龄或发型。
6. 旧提示词、旧SHOT、旧CUT或旧资产是否仍在会话。
7. 当前文字与参考职责是否冲突。

发现冲突时替换错误参考、裁出任务专用图或减少引用。不得保留强错误图，再依赖大量否定词。

## 干净会话重置

以下情况建立新会话或清理当前任务上下文：

- 同一SEG反复修改三次以上仍复现旧错误。
- 已上传多个作废人物、站位或场景版本。
- 模型持续生成已删除的台词、人物、家具或动作。
- 当前输出混合前后两个SEG。
- 引用职责已无法分清。

重置时只保留当前真源、已确认空间、SHOT任务合同、CUT、跨镜状态和必要资产，不复制整段旧对话。

## 原文与分镜差异闸门

提示词输出后逐项核对：

- 每句台词、说话人和顺序。
- 每个task_type要求的可见动作、场景锚点、边界、路径及结果。
- 所有SHOT、CUT点、CUT类型和时间码。
- 出场人物和入画时机。
- scene_id／zone_id／anchor_id、摄影机世界朝向、人物位置、服装和关键道具。
- 起始状态和结束状态。
- 环境声和关键音效。

分类：

- **完全继承**：进入生产版。
- **为了可视化而补足**：不改变剧情、空间或CUT，可保留并注明。
- **可选创作建议**：单列，不进入生产版。
- **未授权漂移**：删除并重新检查时长与连续性。

## 多次生成与停止条件

同一提示词默认先生成2—4个候选，数量服从成本、平台限制和用户要求。

记录：

- 尝试编号、提示词版本和生成参数。
- 实际参考素材。
- 剧情、资产、空间、SHOT任务覆盖、CUT、动作、声音和衔接结果。
- 失败原因、修改点和是否采用。

停止条件：

- 剧情与对白正确。
- 核心资产、世界空间、SHOT任务覆盖和物理关系正确。
- 所有合法CUT得到执行，没有无效相邻跳切。
- 动作完整，结束状态可承接。
- 声音可用或有明确后期方案。
- 没有阻止下一阶段的错误。

画面再漂亮，只要改变剧情、人物身份、世界空间、SHOT任务证据、CUT或关键道具，就不能直接采用。

## 平台适配

保留平台无关的内部导演计划，再输出目标平台版本：

- 需要时间码的平台：保留SHOT时间线。
- 自然语言平台：可删除教学编号，但不能删除动作顺序和CUT边界。
- 普通Seedance多镜头：按已确认SHOT与CUT执行。
- I2V：从明确首帧之后开始描述。
- FLF2V：检查首尾之间物理路径。
- 视频延长：只描述原视频最后状态之后的新内容。
- 不支持多参考的平台：按优先级保留最关键参考。

## 交付与验收

交付当前SEG时包含：

1. 干净可复制的生产版提示词。
2. 当前SHOT、CUT和时间码摘要。
3. 输入包和参考职责映射。
4. 原文与分镜差异检查。
5. 已采用候选和未采用原因。
6. 下一SEG需要继承的状态。

不得把“下一段尾帧”作为所有项目的默认字段；只有明确首尾帧工作流才记录具体图像帧。
