# 零基础逐步带做模式

## 模式目标

让不懂剧本、分镜、提示词或只使用手机的用户，也能逐步获得可生成、可检查、可剪辑的AI短剧。

新手模式只降低沟通门槛，不降低专业验收标准：

1. 一次只解释当前步骤必需知识。
2. 把专业判断转成普通选择。
3. Skill承担结构、读秒、空间、CUT、资产、连续性和提示词工作。
4. 每步交付实际产物，不用概念课代替制作。
5. 未通过当前关卡时先修复，不假装完成。

## 启动条件

出现任一情况时启动：

- 用户说“零基础”“第一次做”“一步一步教我”“从0开始”。
- 用户只有模糊灵感，不知道下一步。
- 用户反复询问术语或复制哪一段。
- 用户已经做了一部分，但无法判断完成度和卡点。
- 用户只使用手机或没有固定工作流。

熟练用户明确要导演版、批量版或纯成品时，不强制解释术语，但仍执行专业检查。

## 第一次回应

信息足够时自动判断起点并直接完成当前关卡的第一份产物，不重复询问。

只有起点无法判断时，给出三个入口；每个可复制回答必须带Skill命令：

```text
A（推荐）：使用 $ai-short-drama-director，选择A：我只有一个灵感或题材。
B：使用 $ai-short-drama-director，选择B：我有小说、故事、大纲或剧本。
C：使用 $ai-short-drama-director，选择C：我已经有图片、分镜、提示词或视频，需要排查问题。
```

不再要求用户只回复裸字母。

## 三种起点

### 起点A：只有灵感

Skill负责补成：

- 一句话故事。
- 核心人物和目标。
- 主要阻力和冲突。
- 开场钩子和结尾体验。
- 建议体量。

最多补问一个会改变故事方向的问题。

### 起点B：已有文字

接受小说、故事、大纲、剧本或零散片段，交付：

- 不可改变事实。
- 可改编范围。
- 人物关系。
- 可视化难点。
- 推荐集数和单集结构。
- 当前最适合制作的一集或一场。

### 起点C：已经做到一半

接受人物图、场景图、分镜、提示词、失败截图、视频或剪辑片段，先判断：

- 真正完成并通过了什么。
- 哪些只是有文件但未通过。
- 当前错误的上游真源。
- 需要回溯哪些文件。
- 最小且完整的修复路径。

用户要求修复时直接交付完整修订版，不只列问题。

## 单步教学循环

每轮按以下顺序：

1. 现在只做什么。
2. 为什么需要，能避免什么失败。
3. 已经继承的关键事实。
4. 用户最多确认一个关键点，或从三个带Skill命令的选项中选择。
5. Skill直接完成当前产物。
6. 按当前关卡标准检查。
7. 更新已完成、未完成和需返工。
8. 末尾给A/B/C三个带Skill调用命令的下一步。

用户已明确本轮任务时先执行，不能用选择题阻塞当前工作。

## 术语翻译

首次出现专业词时使用“普通说法（专业词）”：

| 专业词 | 新手说法 |
|---|---|
| 制片段SEG | 一次交给视频模型生成的10秒或15秒片段 |
| SHOT | 摄影机不切断的一次连续拍摄 |
| CUT | 从一个SHOT切到另一个SHOT |
| 景别 | 人物在画面里有多大 |
| 轴线 | 防止人物左右突然互换的隐形界线 |
| 空间图 | 标清人物、道具和摄影机在哪里的俯视图 |
| 状态继承 | 下一镜承接上一镜结果，但不复制上一画面 |
| I2V | 用一张图作为视频起点 |
| FLF2V | 同时指定开始图和结束图生成视频 |
| 唯一真源 | 所有后续内容服从的最新锁定设定 |

不要一次堆叠超过三个新术语。

## 默认决策与确认边界

可直接采用的可回滚默认项：

- 先做一集或一个完整场景样片。
- 先建立主角、核心场景和关键道具。
- 对无关装饰细节使用明确的中性临时版本。
- 空间可以从已确认资产和上一SHOT唯一推导时，直接建立内部空间表继续。

必须由用户确认的高影响事项：

- 主角身份、核心关系和结局。
- 内容边界和目标平台。
- 是否允许改动原著主线、合并人物或删支线。
- 明显影响成本的工具、集数和总时长。
- 10秒版还是15秒版。
- 关键空间存在两种以上合理布局，且会改变轴线、左右、接触或CUT结果。
- 使用真实人物、受保护IP、未授权声音或他人素材。

只有缺失项会改变当前产物时才提问。

## 十一个制作关卡

### 关卡0：灵感落地

交付一句话故事、主角目标、阻力、卖点、开场钩子和结尾方向。

### 关卡1：故事骨架

交付人物关系、世界规则、起因、升级、转折、高潮和不可矛盾事实。

### 关卡2：素材或小说改编

交付改编边界、主线、必要支线、人物合并建议和可视化改写。

### 关卡3：分集与单集结构

交付分集大纲、每集目标、冲突、转折和结尾钩子。

### 关卡4：可拍摄剧本

交付场景标题、可见动作、完整对白、语气、环境声和音效。

### 关卡5：空间确认、SHOT任务覆盖、CUT与完整分镜

开始前确认10秒版或15秒版。涉及多人、道具、过肩、反打或方向关系时，读取：

- `04-blocking-continuity.md`
- `14-shot-task-action-coverage.md`
- `13-cut-shot-geometry.md`

执行顺序：

```text
锁世界空间 → 拆动作链 → 验证每个SHOT是否真正拍到任务证据
→ 自然切点成立才CUT → 判断30度适用性与视觉差异路径
→ 拦截无意近似跳切 → 锁跨镜状态
→ 再封装10秒／15秒SEG
```

Skill交付：

- 已确认规格。
- scene_id／zone_id／anchor_id、摄影机世界位置与朝向、人物和道具位置、关系轴线。
- SEG、SHOT和CUT编号。
- 每个SHOT的task_type、必要画面证据、动作状态机、机位、景别、动作、对白和声音。
- CUT点、类型、理由、前后状态和视觉差异。
- 空间、轴线、动作和信息可见性检查。

### 关卡6：视觉与资产

交付全局画风、角色、服装、场景、道具、群演和声线资产。

### 关卡7：故事板与图片

故事板只可视化已经通过的SHOT与CUT：

- 每格是关键时间状态，不自动等于SHOT。
- 同一SHOT可跨多个格子。
- 已确认CUT必须标出。
- 下一SHOT继承状态，不复制上一格或上一段最后画面。
- 首尾帧仅在用户明确选择I2V／FLF2V或首尾帧工作流时使用。

### 关卡8：视频提示词

交付当前SEG最小输入包、已确认SHOT和CUT、素材职责、纯净提示词和生成前检查。

### 关卡9：生成、质检与返修

交付可见问题、上游真源、完整修订版、回归检查和下一次生成策略。

### 关卡10：声音、剪辑与成片

交付对白、声线、音效、音乐、剪辑点、CUT衔接和发布前检查。

## 每关通过标准

| 关卡 | 最低通过条件 |
|---|---|
| 灵感 | 能说明主角、目标、阻力和看点 |
| 故事 | 动机成立，冲突升级，结尾明确 |
| 改编 | 保留与改动边界明确，关键事件可视化 |
| 分集 | 每集有目标、升级和尾钩 |
| 剧本 | 关键事件不依赖读原小说才能理解 |
| 分镜 | 规格已确认；空间唯一；SHOT任务覆盖通过；CUT合法；无意近似跳切已排除；时长可实现；状态连续 |
| 资产 | 人物、场景、道具长期特征不冲突 |
| 故事板 | SHOT与CUT标注正确；左右、方向、道具和状态连续 |
| 视频提示词 | 输入精简，CUT保留，引用职责唯一，事件完整 |
| 生成返修 | 通过剧情、资产、空间、SHOT任务覆盖、CUT、声音和衔接检查 |
| 成片 | 无明显漏字、跳变、断声、错误重复和无效跳切 |

## 卡住与失败时的处理

用户不知道怎么选时，给推荐理由和完整调用命令，例如：

```text
使用 $ai-short-drama-director，按推荐方案继续：先修复完整分镜。
```

用户材料不完整时，先完成不受影响部分；只处理一个关键缺口，或提供三条带命令的路径：补充材料、采用可回滚假设、先回查上游真源。

生成失败时依次检查：

1. 合规拦截。
2. SEG负载是否过高。
3. 参考职责是否冲突。
4. 提示词是否混入内部说明。
5. 上游资产、空间、SHOT或CUT是否错误。

不要让用户自己猜，也不要只说“再生成一次”。

## 移动端友好交付

- 先给可直接复制的成品。
- 固定使用“本轮结果、进度更新、自检结论、下一步请选择”。
- 大段提示词使用代码块或文件。
- 一次最多要求确认一个关键点。
- 不默认要求安装开发工具。
- A/B/C可压缩为一行，但每行都必须以 `使用 $ai-short-drama-director` 开头。
- 不再写“直接回复A／B／C”或“用户只需回复字母”。

## 项目进度卡

每轮结束使用 `../assets/beginner-progress-card.md`，显示：

- 当前关卡。
- 本轮完成内容。
- 已锁定内容。
- 未完成与需返工。
- 当前是否通过。
- 三个带Skill命令的下一步选项。

## 完成与交接

达到成片阶段时区分：

- 已完成并通过的交付物。
- 可选优化。
- 最终导出清单。
- 素材授权与来源记录。
- 可复用资产和最后已确认状态。

制作下一集时继承上一集剧情结果和人物状态，不默认复制上一集尾帧或保持同一机位。

## 禁止事项

- 不在第一次回应倾倒全部关卡。
- 不让用户先学术语再开始。
- 不要求重复提供已上传或确认的信息。
- 不用“自己调整”“多试几次”代替具体修复。
- 不把固定镜头密度、固定画幅或一镜到底当通用答案。
- 不跳过空间和CUT硬检查。
- 不把教程、自检、ABC导航或Skill命令混入生成提示词。
- 不省略A/B/C，也不给超过三个选项。
- 不让A/B/C的可复制回答缺少 `使用 $ai-short-drama-director` 开头。
- 不承诺绝对完美或保证过审。
