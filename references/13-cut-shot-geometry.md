# CUT切镜与相邻SHOT视觉几何规则

## 唯一职责

本文件是以下内容的唯一规则真源：

- 何时形成有效CUT点。
- 下一SHOT是否具有独立叙事任务。
- CUT类型是否与动作进度一致。
- 相邻SHOT视觉差异、30度适用性、同轴景别路径与近似跳切判定。
- MATCH-ON-ACTION的跨机位动作衔接。
- 过肩、反打、主观和插入镜头的几何合法性。
- 每个SHOT与CUT的强制输出字段和审核流程。

本文件不负责定义人物坐标、场景锚点、关系轴线、状态继承明细或信息可见性标准；这些只由`04-blocking-continuity.md`定义。

只要任务涉及完整分镜、段内镜头、故事板格序、视频提示词中的机位变化、镜头复审或剪辑衔接，就必须读取本文件，并先取得`04`提供的唯一空间状态。

## 优先级

1. 用户本轮明确锁定的切镜要求。
2. `04`已确认的空间状态与上一SHOT结束状态。
3. 本文件的CUT和机位几何规则。
4. SEG时长、提示词密度与目标模型负载。

下游规则只能调整SEG封装，不能吞并已经通过本文件审核的SHOT边界。

## 核心原则

默认不是“能不切就不切”，而是：

> 当前动作、视线、反应、信息、对白重心、时间或空间节点形成明确结果，并且下一SHOT承担独立且具有叙事作用的画面任务时，立即CUT。

同时满足两个条件才成立：

1. **切点成立**：当前动作或信息节点已形成可识别结果。
2. **新镜头成立**：下一SHOT具有独立叙事任务和足够视觉差异。

“能切就切”不等于机械拆碎。以下情况不能单独构成CUT：

- 一句普通台词结束，但叙事重心没有改变。
- 眨眼、呼吸、轻微转头、抬手或走一小步。
- 只想更近、更正、更好看或补一个正脸。
- 谁说话就机械切到谁。
- 为填满九宫格、十二宫格或时间轴而切。
- 下一SHOT没有新主体、新阶段、新信息、新视角、新关系或新空间任务。

判断句：

```text
切点成立就CUT；切点不成立就继续演。
CUT成立后，必须切到视觉任务明显不同的新镜头，不能切到旁边那个几乎一样的镜头。
```

## SHOT与SEG分离

- `SHOT`：一次连续摄影机记录。
- `CUT`：SHOT之间的切换。
- `SEG`：一次交给视频模型生成的10秒或15秒单元。

执行顺序：

```text
01拆剧情与动作链
→ 04锁空间、轴线、状态和可见性
→ 本文件决定SHOT与CUT并审核几何
→ 返回01封装SEG
```

提示词合并不等于镜头合并。禁止先凑满SEG时长，再临时编镜头。

用户明确“每10秒一镜”时，每个10秒SEG必须且只能包含1个SHOT；该SEG内部不包含CUT。CUT只存在于相邻SHOT之间，也就是当前SEG结束与下一SEG开始的边界。

## 有效CUT触发条件

以下节点形成明确结果，且下一SHOT具有独立任务时，应CUT。

### 1. 动作完成点

例如：

- 人物走到指定位置并停稳。
- 坐下、站起、落地、跌倒或转身完成。
- 门完全打开／关闭。
- 道具完成拿取、放置或交接。
- 人物进入或离开画面。

动作结果未形成时，不得把普通CUT写成完成点。

### 2. 动作阶段转换

例如：

- 行走 → 停下观察。
- 观察 → 发现目标。
- 发现 → 靠近。
- 对话 → 行动。
- 推门 → 进入。
- 对峙 → 动手。
- 怀疑 → 确认。

阶段变化只是候选切点；若下一阶段没有独立镜头任务，应继续当前SHOT。

### 3. 视线落点

人物已经明确找到目标后，可以使用`EYELINE CUT`切到目标。

禁止：

- 人物尚未找到目标就提前切。
- 前镜已看见目标，后镜重新寻找或重新发现。
- 目标方向与`04`锁定的视线关系不符。

### 4. 有剧情作用的反应

关键信息导致人物立场、情绪、权力关系或行动目标改变时，可以使用`REACTION CUT`。

普通眨眼、呼吸或无剧情作用的微表情不单独成镜。

### 5. 对白重心转换

以下情况可以CUT：

- 关键问题提出。
- 核心回答出现。
- 谎言被识破。
- 威胁正式成立。
- 听者反应比说话者更重要。
- 对话转为行动。

禁止因为说话者变化就机械正反打。

### 6. 新主体或新信息

关键人物、道具、异常细节、环境威胁或被观察对象成为新的叙事主体时，应独立构图。

新信息必须在`04`判定为当前机位可见；不可见时需要重新设计机位或切到细节镜头。

### 7. 空间节点

人物跨越门槛、窗、屏风、床幔、回廊转角、楼梯、院门或室内外边界时，可以使用`SPACE CUT`。

同一房间内门板关闭、灯光变暗或人物仍停留原地，不自动构成SPACE CUT。

### 8. 时间节点

明显时间跳跃、昼夜变化、多日蒙太奇、梦境、回忆或幻觉切换，使用`TIME CUT`。

### 9. 遮挡与声音桥

门板、人物身体、柱子、床幔或黑暗区域遮满画面时可以CUT；声音可提前进入或延后退出。

遮挡和声音只是连接手段，不能替代“下一SHOT必须有独立任务”的判断。

## CUT类型

- **普通CUT**：当前动作或阶段已经完成，下一镜承接结果。
- **MATCH-ON-ACTION**：未完成动作跨机位继续。
- **REACTION CUT**：切到具有剧情作用的反应。
- **EYELINE CUT**：视线落定后切到目标。
- **INSERT CUT**：关键道具、手部或细节成为新主体。
- **SPACE CUT**：跨越明确空间边界。
- **TIME CUT**：时间、梦境或回忆变化。
- **POV CUT**：客观镜头切到人物主观视角。
- **END**：本场、本集或当前叙事单元结束。

常见误标：

- 动作已经落稳后仍标MATCH-ON-ACTION。
- 同房间关门却标SPACE CUT。
- 切到人物台词后的结果却把前镜标REACTION CUT。
- 最后一镜仍写普通CUT而没有后续SHOT。

## MATCH-ON-ACTION

动作未完成时，只有使用MATCH-ON-ACTION才能跨机位：

```text
前镜：动作已开始但未完成
→ CUT
→ 后镜从同一动作进度继续
```

必须继承`04`锁定的：

- 动作方向与速度。
- 身体重心和发力状态。
- 手脚位置。
- 道具、门窗或机关进度。
- 人物所在空间与接触关系。

禁止：

- 前镜已经完成动作，后镜重新从起点表演。
- 前镜人物仍在地面，后镜无过程已经落到高处。
- 前镜门只打开三分之一，后镜突然完全关闭。

## 相邻SHOT视觉差异闸门

“相邻SHOT”只表示剪辑顺序相邻，本身不是错误。真正需要拦截的是：前后SHOT在同一主体、连续时空、近似动作阶段、近似机位与近似景别下，只产生无意的画面跳动，却没有新的视觉任务。

任何CUT必须先满足“切点成立＋下一SHOT具有独立叙事任务”，再从以下视觉差异路径中至少通过一条。各路径是替代关系，不是累计硬门槛。

### 路径A：30度角度路径

30度规则只在以下条件同时成立时重点适用：

- 前后SHOT的主要主体相同。
- 时间与空间连续。
- 观察视角没有从客观切为POV、插入或其他独立视角。
- 景别相同或只相差一级。
- 构图重心、人物关系和动作阶段仍然近似。

角度必须在主要主体处计算：

```text
A = angle(主体 → 摄影机C1, 主体 → 摄影机C2)
```

不得用摄影机自身偏航角、人物转头角度、镜头焦段变化或画面左右位移冒充30度机位差。

当本路径适用时，前后摄影机方向夹角原则上至少为30度，并且仍须服从`04`锁定的180度关系轴线、运动轴线和摄影机允许区。

### 路径B：同轴大景别路径

摄影机可以保持同一观察轴、接近同一观察轴，或在角度不足30度时通过足够大的景别与构图范围变化建立新镜头。严格同轴只是本路径的一种典型情况。

本文件中的“同轴”指主体到摄影机的观察射线基本一致，通常夹角不超过约10度；它不等于`04`中的180度关系轴线，两者不得混淆。

标准景别阶梯：

```text
大远景 → 远景／全景 → 中远景 → 中景
→ 中近景 → 近景 → 特写 → 大特写／极近特写
```

同轴硬切原则上至少跨越两级，也就是跳过至少一个相邻景别，并同时改变镜头任务或构图信息范围。

合法示例：

- 正面眼部极近特写 → 同轴正面中景：心理反应转为全身动作。
- 全景 → 同轴近景：空间建立转为关键人物决定。

错误示例：

- 中景 → 同轴中近景，人物、动作、背景和任务都基本不变。
- 只改变焦段或轻微放大，却声称产生了新SHOT。

角度路径与同轴大景别路径是替代关系，不是“既要30度又要跨两级”的累计要求。

### 路径C：主体、视角、时间或空间变化路径

以下任一项发生实质变化时，30度规则通常标记为“不适用”，但仍须检查空间连续性、视线匹配和新镜头任务：

- 主要主体改变，例如人物切到其视线目标或关键道具。
- 客观视角切为POV、过肩关系视角或独立插入镜头。
- 时间、场景或叙事空间发生明确变化。
- 双人关系镜头切为承担关键反应的单人镜头。

“不适用”不是免检。下一SHOT仍须具有清楚的新主体、新信息、新关系或新视角。

### 路径D：组合视觉差异路径

若角度不足30度、景别又只变化一级，仍可在多个独立变化共同成立时通过，但不能只靠一个轻微变化。

可计入的视觉变化包括：

- 摄影机角度达到约15—29度。
- 景别变化一级。
- 摄影机高度明显变化。
- 构图重心或焦点主体明确改变。
- 空间层次、人物关系或屏幕关系明显改变。

第二项可以是另一视觉变化，也可以是明确的动作阶段、新增叙事信息或权力关系重点。至少一项必须是视觉几何变化。

以下情况仍然失败：

- 摄影机只轻微左移、右移、升高或降低。
- 同一主体、同一动作、同一背景只稍微变近或变远。
- 只有情绪名称或台词变化，画面几何几乎不变。
- 画面只是“跳一下”，没有新的构图任务。

### 路径E：有意跳切

只有用户或导演明确要求跳切、重复、断裂或时间压缩风格时，才可使用有意跳切路径。必须写明跳切目的、节奏和连续性处理，不能把无意错误事后解释成风格。

## 视觉差异充分性

判断优先级：

1. **强差异**：主要主体／POV／时间空间改变、角度达到30度、或景别跨越至少两级。任一项成立，并且新镜头任务成立，即可通过。
2. **组合差异**：没有单项强差异时，至少两个独立变化共同成立，其中至少一项是视觉几何变化。
3. **弱差异**：小于约15度的轻微机位变化、一个相邻景别、轻微高度变化或仅换台词，单独不能支持CUT。

因此，“每次CUT必须同时满足30度＋跨两级＋两个视觉变量”是错误理解。正确逻辑是先判断30度是否适用，再选择一条合法视觉差异路径。

## 近似跳切判定

满足以下组合时，默认判定为无效近似跳切：

- 主要主体相同；
- 时间与空间连续；
- 观察视角相同；
- 摄影机夹角小于约15度；
- 景别相同或只差一级；
- 构图、动作阶段和叙事任务基本不变；
- 用户没有明确要求有意跳切。

出现该组合时，必须取消CUT，或重新设计角度、景别、主体、视角、构图任务中的至少一项。

## 摄影机设计顺序

机位设计必须依赖`04`的空间事实，按以下顺序：

1. 当前镜头叙事任务。
2. 人物正在看谁、去哪里、做什么。
3. 人物身体和头部朝向。
4. 关系轴线、运动轴线与摄影机允许区。
5. 当前信息需要的景别、角度和焦点。
6. 与上一机位的视觉差异。
7. CUT后是否完整继承上一SHOT结果。

需要正脸时移动摄影机，不得让人物无理由转向镜头。

## 过肩、反打与主观镜头

### 过肩镜头

必须写清：

- 左肩还是右肩。
- 前景人物的姿态、朝向和视线。
- 前景是否虚焦，是否仍需承担信息。
- 清晰主体位于画面哪一侧。
- 相比上一机位的角度变化。
- 摄影机是否仍位于`04`锁定的同一轴线侧。

禁止上一镜正面拍人物，下一镜无几何说明地直接跳到正后方。

### 反打镜头

必须保持`04`锁定的屏幕左右和视线匹配，且新镜头承担新的反应、信息或权力关系任务。禁止只因换说话人就反打。

### POV镜头

前镜必须先建立人物视线和目标方向；POV内容必须与该人物实际可见范围一致。

## 状态与可见性前置条件

每个CUT必须通过`04-blocking-continuity.md`的两项审核：

1. **状态继承通过**：下一SHOT起始状态完整继承仍然成立的人物、动作、道具和场景状态。
2. **信息可见性通过**：当前景别、光线、焦点和遮挡确实能看到所描述的信息。

本文件不重复维护状态字段清单和可见性细则；若`04`判定失败，本CUT自动失败。

## 每个SHOT强制格式

```markdown
### SHOT XX｜时长

- 镜头任务：本镜独立负责什么。
- 空间状态引用：04中的场景／SHOT状态编号。
- 景别：
- 摄影机位置：相对于人物、场景锚点和轴线。
- 摄影机角度：
- 人物位置与朝向：引用04并写本镜可见关系。
- 起始状态：引用04中的上一SHOT继承状态。
- 镜头内容：按真实时间顺序。
- CUT点：具体动作、视线、台词、反应、遮挡、时间或空间节点。
- CUT类型：普通／MATCH-ON-ACTION／REACTION／EYELINE／INSERT／SPACE／TIME／POV／END。
- CUT理由：下一SHOT的新任务；终镜写本场／本集结束。
- CUT前结束状态：写结果并同步回04状态表。
- 下一SHOT起始状态：引用04的继承结果；终镜可写无／已知下一集状态。
- 相邻SHOT差异路径：角度／同轴大景别／主体或视角变化／组合差异／有意跳切；终镜写不适用。
- 30度适用性：适用／不适用；适用时写主体处夹角，不适用时写替代路径。
- 景别差异：前后景别与跨级数。
- 视觉差异结论：强差异／组合差异／需返工。
- 几何检查：180度轴线侧、运动轴线、过肩／反打关系。
- CUT结论：通过／需返工。
```

禁止写“适时切镜”“自然切镜”“情绪到位后切”。CUT点必须是可识别的具体节点。

## CUT审核流程

### 第一步：当前节点是否形成结果

确认动作、视线、信息、情绪、对白、时间或空间节点已经成立。未成立则继续当前SHOT。

### 第二步：下一镜是否具有独立任务

必须出现新主体、新阶段、新信息、新视角、新人物关系、新情绪重点或新空间任务。没有则不CUT。

### 第三步：空间与状态是否通过04

确认位置、轴线、屏幕方向、动作进度、道具状态和信息可见性均通过。任一失败则返工。

### 第四步：选择相邻SHOT视觉差异路径

先判断30度规则是否适用，再在角度、同轴大景别、主体或视角变化、组合差异、有意跳切中选择一条合法路径。不得把30度、景别跨级和组合差异写成同时必须满足。

### 第五步：视觉差异是否充分

确认存在一项强差异，或至少两项独立的组合差异且包含视觉几何变化。只有轻微角度、一个相邻景别或近似构图时，重新设计或取消CUT。

### 第六步：CUT类型是否与动作进度一致

动作未完成只能使用MATCH-ON-ACTION；动作已完成不得误标MATCH。

六步全部通过，CUT才成立。

## 故事板与视频提示词约束

- 九宫格、十二宫格或其他格数不等于SHOT数量。
- 一个SHOT可以占多个格子；一个SEG可以包含多个已确认SHOT。
- 故事板和视频提示词必须保留已通过的SHOT边界、CUT点和类型。
- 下游模型负载过高时拆分SEG，不删除合法CUT。
- 普通多镜头流程使用状态继承，不默认复制上一尾帧；首尾帧工作流仅在用户明确采用I2V、FLF2V或视频延长时启用。

## 本文件自检

- 每个CUT都有具体节点。
