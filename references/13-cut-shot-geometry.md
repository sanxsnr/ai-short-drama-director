# CUT切镜与相邻镜头几何规则

## 适用范围与优先级

只要任务涉及完整分镜、段内镜头、故事板格序、视频提示词中的机位变化、镜头复审或剪辑衔接，就必须读取本文件，并同时读取 `04-blocking-continuity.md`。

本文件是仓库中 CUT 决策、相邻镜头几何和跨镜状态继承的唯一规则真源。其他文件如果出现“优先少切”“固定镜头密度”“默认保持同一机位”“切镜频繁就合并”等表述，必须服从本文件，不得删除已经通过审核的有效CUT。

优先级：

1. 用户本轮明确锁定的切镜要求。
2. 已确认的空间图、人物状态和前一SHOT结束状态。
3. 本文件的CUT与机位几何规则。
4. 制片段时长、提示词密度和目标模型负载规则。

后面的规则只能调整SEG封装和提示词负载，不能反向吞并已经成立的SHOT边界。

## 核心原则：自然切点成立就CUT

默认不是“能不切就不切”，而是：

> 当前动作、视线、反应、信息、对白重心或空间节点形成明确结果，并且下一镜承担独立且具有叙事作用的画面任务时，立即CUT。

“独立画面任务”必须带来新的主体、动作阶段、信息、视角、人物关系、情绪重点或空间关系。单纯为了换一个好看的构图、拍正脸或略微推近，不属于独立任务。

不得为了追求一镜到底，把多个已经成立的CUT点强塞进一个过载SHOT；也不得把每个小动作机械拆镜。

以下情况不能单独构成CUT：

- 一句普通台词结束，但叙事重心没有变化。
- 眨眼、轻微转头、抬手、呼吸或走一小步。
- 只想更近一点、更正一点或补一个好看角度。
- 谁说话就切到谁。
- 为填满九宫格、十二宫格或时间轴行数而切。
- 下一镜没有独立叙事任务。

## SHOT与制片段必须分开

- `SHOT`：一次连续摄影机记录，SHOT之间通过CUT连接。
- `SEG`／制片段：一次交给视频模型生成的10秒或15秒单元，可以包含一个或多个已经确认的SHOT。

执行顺序：

```text
锁空间 → 拆动作链 → 决定SHOT与CUT → 审核相邻机位
→ 锁定跨镜状态 → 再封装SEG与生成提示词
```

禁止先凑满10秒或15秒，再临时编机位。

用户明确要求“每10秒一镜”时，一个10秒SHOT内部不得再出现第二次CUT。用户要求“10秒片段内多镜头”时，必须列出段内全部SHOT、时间码和CUT点。

## 有效CUT触发条件

以下节点形成明确结果，且下一镜具有独立叙事任务时，应CUT。

### 1. 动作完成点

例如：走到指定位置并停下、坐稳、站稳、落地、门完全打开、道具完成交接、人物离开画面。

### 2. 动作阶段转换

例如：

- 行走 → 停下观察
- 观察 → 发现
- 发现 → 靠近
- 对话 → 行动
- 推门 → 进入
- 对峙 → 动手
- 怀疑 → 确认

动作阶段变化只是候选切点；下一阶段仍需具备独立画面任务，否则继续当前SHOT。

### 3. 视线落点

人物已经明确找到目标后，可以使用 `EYELINE CUT` 切到目标。人物尚未找到目标时不得提前切。

### 4. 有剧情作用的反应

关键信息导致人物立场、情绪或行动目标改变时，可以使用 `REACTION CUT`。普通微表情不单独成镜。

### 5. 对白重心转换

关键问题、核心回答、谎言被识破、威胁成立、听者反应变得比说话者更重要时，可以CUT。禁止机械正反打。

### 6. 新主体或新信息

关键人物、道具、异常细节、环境威胁或被观察对象成为新的叙事主体时，应独立构图。

### 7. 空间节点

人物跨越门槛、窗、屏风、床幔、回廊转角、楼梯、院门或室内外边界时，可以使用 `SPACE CUT`。

同一房间内门板关闭、灯光变暗或人物仍停留原地，不自动构成SPACE CUT；此时根据实际任务使用普通CUT、遮挡CUT或不切。

### 8. 时间节点

明显时间跳跃、昼夜变化、多日蒙太奇、梦境、回忆或幻觉切换，使用 `TIME CUT`。

### 9. 遮挡与声音桥

门板、人物身体、柱子、床幔、黑暗区等遮满画面时可以CUT；下一场声音可提前进入或上一场声音可延后退出。遮挡和声音只是连接方式，新画面仍需拥有独立任务并通过相邻镜头审核。

## 动作中的CUT

动作未完成时，只有使用 `MATCH-ON-ACTION CUT` 才能跨机位：

```text
前镜：动作已经开始但尚未完成 → CUT → 后镜从同一动作进度继续
```

必须连续：

- 动作方向与速度
- 身体发力与重心
- 手脚位置
- 道具、门窗或机关的当前进度
- 人物所在空间

禁止前镜已完成动作，后镜又从动作起点重演。禁止前镜人物仍在地面，后镜无过程地已经落到高处。

## 禁止切到相邻镜头

CUT后的下一镜不得只是上一镜旁边的轻微变化。

禁止：

- 相邻摄影机位置。
- 轻微偏左、偏右、升高或降低。
- 同一主体、同一动作、同一背景的近似构图。
- 只比上一镜稍近或稍远。
- 同方向、同主体只改变一个相邻景别。
- 主体大小、视线、动作和信息基本不变。

### 30度规则

拍摄同一主体、同一动作或同一空间时，相邻两个机位的夹角原则上至少变化30度，同时不得越过180度轴线。

主体、场景或时间已经完全改变时，30度规则可标记为“不适用”，但仍需检查构图差异和叙事连续性。

### 景别跨级规则

同一主体、同一方向、同一动作连续切镜时，景别原则上至少跨越两级，例如：

- 全景 → 中景
- 中景 → 特写
- 双人中景 → 单人近景／特写

只变化一级时，必须同时明显改变主体、角度、高度、视角、人物关系或叙事信息，否则禁止CUT。

### 两变量规则

每次CUT至少改变两个有效变量，其中至少一项必须来自“视觉几何变量”。

视觉几何变量：

1. 摄影机角度
2. 景别
3. 画面主体
4. 观察视角
5. 构图重心
6. 摄影机高度
7. 空间层次
8. 人物关系

第二项可以来自上述视觉变量，也可以是：

9. 动作阶段
10. 新增叙事信息
11. 情绪或权力关系重点

不能只依靠“动作阶段变化＋新增信息”两项，在几乎相同的机位和构图之间硬切。

## 摄影机设计顺序

必须按以下顺序：

1. 人物正在看谁。
2. 人物准备去哪里。
3. 人物正在做什么。
4. 人物身体与头部应朝哪个方向。
5. 人物之间的关系轴线和运动轴线。
6. 摄影机应位于轴线哪一侧。
7. 选择能清楚展示当前信息的景别和角度。

需要正脸时移动摄影机，不得让人物无理由转向镜头。

## 过肩镜头与轴线

从人物正面镜头切到过肩镜头时，必须说明摄影机从上一机位移动到人物哪一侧，并确认仍在同一轴线侧。

过肩镜头必须写清：

- 使用左肩还是右肩。
- 前景人物当前姿态、朝向和视线。
- 前景是否虚焦，是否仍需承担信息。
- 主体位于画面哪一侧。
- 摄影机与上一镜夹角。
- 是否保持屏幕左右关系。

禁止上一镜正面拍人物，下一镜无几何说明地直接跳到人物正后方。

## CUT后的状态继承

普通连续CUT必须继承：

- 人物所在空间区域和相对位置。
- 身体大方向、头部方向和视线目标。
- 屏幕左右关系和行进方向。
- 动作完成程度、速度和发力状态。
- 持物手、支撑手、接触关系和道具归属。
- 坐、站、跪、躺、被捆、醉酒、受伤、虚弱等持续状态。
- 门窗、床幔、灯具和机关的开合状态。
- 服装、发型、污渍、雨水、战损和环境光线。
- 已经发生的剧情结果。

下一镜起始状态必须同时写仍然存在的旧主体和新主体，不得只描述新出场人物。

禁止重新抬头、重新坐下、重新拿道具、重新推门、重新寻找已经发现的目标。

### 时间、场景和梦境切换的例外

TIME CUT、明确场景转换、梦境或回忆切换时，不要求人物屏幕左右和原空间坐标继续保持；相关项目标记为“不适用”。但必须明确：

- 哪些状态因叙事转换而改变。
- 哪些人物、服装、伤势、道具或剧情结果仍需继承。
- 时间或空间变化如何被观众识别。

不得用“连续性全部正确”掩盖真实的时间或场景跳变。

## 信息可见性检查

每个镜头只能承担当前景别、光线、遮挡和焦点真正能看见的信息。

- 瞳孔内部变化：近景、特写或大特写。
- 手腕绳结、手指操作：手部近景或插入镜头。
- 中远景逆光人物：不能同时展示微小瞳孔或细微表情。
- 虚焦前景人物：不能承担关键动作或关键信息。
- 被遮挡的道具或接触点：必须换到可见机位。
- 双手反捆在背后时，人物不能用视线直接看到背后绳结。

关键细节若当前机位看不见，应CUT到独立镜头，不能靠文字强塞。

## 每个SHOT强制字段

```markdown
### SHOT XX｜时长

- 镜头任务：本镜只负责什么。
- 景别：
- 摄影机位置：相对于人物、场景和轴线。
- 摄影机角度：
- 人物位置与朝向：
- 起始状态：继承上一镜结束状态；首镜写明场景初始状态。
- 镜头内容：按真实时间顺序。
- CUT点：具体动作、视线、台词、反应、遮挡或空间节点。
- CUT类型：普通CUT／MATCH-ON-ACTION／REACTION／EYELINE／INSERT／SPACE／TIME／POV／END。
- CUT理由：下一镜的新任务；终镜写“本场／本集结束”。
- CUT前结束状态：
- 下一镜起始状态：终镜可写“无／已知下一集状态”，不得为填字段擅自续写剧情。
- 视觉差异检查：至少两个变量；终镜写“不适用”。
- 连续性检查：轴线、左右、动作、视线、道具与可见性；不适用项明确标注。
```

禁止写“适时切镜”“自然切镜”“情绪到位后切”等无法执行的描述。

## 强制决策流程

每次准备CUT时依次回答：

1. 当前节点是否已经形成明确结果？
2. 下一镜是否有独立且具有叙事作用的新任务？
3. 下一镜是否不是相邻机位、相邻景别或近似构图？
4. 是否至少改变两个变量，且至少一个是视觉几何变量？
5. 连续CUT所需继承项是否正确；不适用项是否有明确理由？
6. 当前景别和光线是否真的能展示所写信息？

适用项目全部通过后才执行CUT。若第1项未成立，继续当前SHOT或使用动作匹配CUT；若第2—4项未成立，删除CUT或重设机位；若第5—6项未成立，先修空间与可见性。

## 硬性禁止

- 不以“尽量少切”为默认原则。
- 不把多个已成立的CUT点吞并成一个过载SHOT。
- 不把提示词分组当成SHOT划分。
- 不切到相邻机位、相邻景别或近似构图。
- 不无理由越轴。
- 不为拍正脸让人物转向摄影机。
- 不让下一镜重演上一镜已经完成的动作。
- 不在一个机位中同时描述其无法看见的关键细节。
- 不用“或”“可能”“大概”保留多个互相冲突的空间状态。
- 不为填写下一镜字段擅自续写用户未提供的剧情。
