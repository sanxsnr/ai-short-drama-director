# CUT切镜与相邻镜头几何规则

## 唯一职责

本文件是以下内容的唯一规则真源：

- 何时形成有效CUT点。
- 下一SHOT是否具有独立叙事任务。
- CUT类型是否与动作进度一致。
- 相邻机位、相邻景别、30度规则与两变量规则。
- MATCH-ON-ACTION的跨机位动作衔接。
- 过肩、反打、主观和插入镜头的几何合法性。
- 每个SHOT与CUT的强制输出字段和审核流程。

本文件不负责定义人物坐标、场景锚点、关系轴线、状态继承明细或信息可见性标准；这些只由`04-blocking-continuity.md`定义。

只要任务涉及完整分镜、段内镜头、故事板格序、视频提示词中的机位变化、镜头复审或剪辑衔接，就必须读取本文件，并先取得`04`提供的唯一空间状态。

## 优先级

1. 用户本轮明确锁定的切镜要求。
2. `04`已确认的空间状态与上一SHOT结束状态。
3. 本文件的CUT和机位几何规则。
4. SEG时长、提示词密度与目标模型负载。

下游规则只能调整SEG封装，不能吞并已经通过本文件审核的SHOT边界。

## 核心原则

默认不是“能不切就不切”，而是：

> 当前动作、视线、反应、信息、对白重心、时间或空间节点形成明确结果，并且下一SHOT承担独立且具有叙事作用的画面任务时，立即CUT。

同时满足两个条件才成立：

1. **切点成立**：当前动作或信息节点已形成可识别结果。
2. **新镜头成立**：下一SHOT具有独立叙事任务和足够视觉差异。

“能切就切”不等于机械拆碎。以下情况不能单独构成CUT：

- 一句普通台词结束，但叙事重心没有改变。
- 眨眼、呼吸、轻微转头、抬手或走一小步。
- 只想更近、更正、更好看或补一个正脸。
- 谁说话就机械切到谁。
- 为填满九宫格、十二宫格或时间轴而切。
- 下一SHOT没有新主体、新阶段、新信息、新视角、新关系或新空间任务。

判断句：

```text
切点成立就CUT；切点不成立就继续演。
CUT成立后，必须切到视觉任务明显不同的新镜头，不能切到旁边那个几乎一样的镜头。
```

## SHOT与SEG分离

- `SHOT`：一次连续摄影机记录。
- `CUT`：SHOT之间的切换。
- `SEG`：一次交给视频模型生成的10秒或15秒单元。

执行顺序：

```text
01拆剧情与动作链
→ 04锁空间、轴线、状态和可见性
→ 本文件决定SHOT与CUT并审核几何
→ 返回01封装SEG
```

提示词合并不等于镜头合并。禁止先凑满SEG时长，再临时编镜头。

用户明确“每10秒一镜”时，每个10秒SEG必须且只能包含1个SHOT；该SEG内部不包含CUT。CUT只存在于相邻SHOT之间，也就是当前SEG结束与下一SEG开始的边界。

## 有效CUT触发条件

以下节点形成明确结果，且下一SHOT具有独立任务时，应CUT。

### 1. 动作完成点

例如：

- 人物走到指定位置并停稳。
- 坐下、站起、落地、跌倒或转身完成。
- 门完全打开／关闭。
- 道具完成拿取、放置或交接。
- 人物进入或离开画面。

动作结果未形成时，不得把普通CUT写成完成点。

### 2. 动作阶段转换

例如：

- 行走 → 停下观察。
- 观察 → 发现目标。
- 发现 → 靠近。
- 对话 → 行动。
- 推门 → 进入。
- 对峙 → 动手。
- 怀疑 → 确认。

阶段变化只是候选切点；若下一阶段没有独立镜头任务，应继续当前SHOT。

### 3. 视线落点

人物已经明确找到目标后，可以使用`EYELINE CUT`切到目标。

禁止：

- 人物尚未找到目标就提前切。
- 前镜已看见目标，后镜重新寻找或重新发现。
- 目标方向与`04`锁定的视线关系不符。

### 4. 有剧情作用的反应

关键信息导致人物立场、情绪、权力关系或行动目标改变时，可以使用`REACTION CUT`。

普通眨眼、呼吸或无剧情作用的微表情不单独成镜。

### 5. 对白重心转换

以下情况可以CUT：

- 关键问题提出。
- 核心回答出现。
- 谎言被识破。
- 威胁正式成立。
- 听者反应比说话者更重要。
- 对话转为行动。

禁止因为说话者变化就机械正反打。

### 6. 新主体或新信息

关键人物、道具、异常细节、环境威胁或被观察对象成为新的叙事主体时，应独立构图。

新信息必须在`04`判定为当前机位可见；不可见时需要重新设计机位或切到细节镜头。

### 7. 空间节点

人物跨越门槛、窗、屏风、床幔、回廊转角、楼梯、院门或室内外边界时，可以使用`SPACE CUT`。

同一房间内门板关闭、灯光变暗或人物仍停留原地，不自动构成SPACE CUT。

### 8. 时间节点

明显时间跳跃、昼夜变化、多日蒙太奇、梦境、回忆或幻觉切换，使用`TIME CUT`。

### 9. 遮挡与声音桥

门板、人物身体、柱子、床幔或黑暗区域遮满画面时可以CUT；声音可提前进入或延后退出。

遮挡和声音只是连接手段，不能替代“下一SHOT必须有独立任务”的判断。

## CUT类型

- **普通CUT**：当前动作或阶段已经完成，下一镜承接结果。
- **MATCH-ON-ACTION**：未完成动作跨机位继续。
- **REACTION CUT**：切到具有剧情作用的反应。
- **EYELINE CUT**：视线落定后切到目标。
- **INSERT CUT**：关键道具、手部或细节成为新主体。
- **SPACE CUT**：跨越明确空间边界。
- **TIME CUT**：时间、梦境或回忆变化。
- **POV CUT**：客观镜头切到人物主观视角。
- **END**：本场、本集或当前叙事单元结束。

常见误标：

- 动作已经落稳后仍标MATCH-ON-ACTION。
- 同房间关门却标SPACE CUT。
- 切到人物台词后的结果却把前镜标REACTION CUT。
- 最后一镜仍写普通CUT而没有后续SHOT。

## MATCH-ON-ACTION

动作未完成时，只有使用MATCH-ON-ACTION才能跨机位：

```text
前镜：动作已开始但未完成
→ CUT
→ 后镜从同一动作进度继续
```

必须继承`04`锁定的：

- 动作方向与速度。
- 身体重心和发力状态。
- 手脚位置。
- 道具、门窗或机关进度。
- 人物所在空间与接触关系。

禁止：

- 前镜已经完成动作，后镜重新从起点表演。
- 前镜人物仍在地面，后镜无过程已经落到高处。
- 前镜门只打开三分之一，后镜突然完全关闭。

## 禁止切到相邻镜头

CUT后的下一SHOT不得只是上一机位旁边的轻微变化。

禁止：

- 摄影机只轻微左移、右移、升高或降低，主体大小与构图基本不变。
- 同一主体、同一动作阶段、同一背景的近似构图。
- 只比上一镜稍近或稍远，且没有新的镜头任务。
- 主体、视角、动作和信息基本不变，画面只产生“跳一下”的感觉。
- 为满足形式规则强行改变机位，却破坏`04`锁定的朝向、轴线或唯一方案。

“相邻景别”或“小于30度”本身不是自动错误；真正的错误是前后SHOT缺少足够视觉差异和独立叙事任务。

## 视觉差异判定总则

30度、景别跨级和两变量不是三项必须同时满足的独立硬门槛。它们共同服务于一个目标：

> 防止连续CUT落在近似主体、近似构图和近似动作阶段之间，形成无动机跳切。

每个非终点CUT必须先通过“切点成立＋下一SHOT有独立任务”，再通过以下一种视觉差异路径：

1. **标准两变量路径**：至少改变两个有效维度，其中至少一项为视觉几何维度。
2. **主导变化路径**：存在一个足以重新定义画面关系的主导变化，并写明其独立叙事任务。

不能先用30度或景别数字为CUT找理由。CUT动机、`04`空间合法性和180度轴线均高于30度经验规则。

## 30度规则的适用性

30度规则不是所有CUT的强制条件。只有相邻SHOT同时满足以下条件时，才进入“30度适用”状态：

- 主要主体相同。
- 时间与空间连续。
- 动作处于同一阶段或同一未完成动作。
- 景别相同或只相差一级。
- 观察视角相同，例如都为客观视角、都为同侧过肩。
- 构图重心、主体大小和背景关系近似。

任一条件不成立时，30度可以标记为“豁免”或“不适用”，但仍必须通过视觉差异判定。

### 角度如何计算

30度指以前后两个摄影机位置和主要主体形成的水平夹角：

```text
摄影机C1 → 主要主体 ← 摄影机C2
```

它不是：

- 人物转头角度。
- 摄影机摇摄或俯仰角度。
- 镜头焦距差。
- 画面中主体倾斜角度。

### 适用时的硬要求

当30度规则适用时：

- 机位夹角原则上应达到或超过30度。
- 两个机位必须仍服从`04`锁定的关系轴线、运动轴线和摄影机允许区。
- **180度轴线优先于30度。不得为了凑30度越轴。**
- 若合法半空间内无法取得足够角度，优先改变景别、主体、观察视角、构图层次或取消该CUT。

以下属于典型失败：

- 正面中景 → 轻微偏左正面中景。
- 同一侧面 → 轻微偏前侧面，主体大小不变。
- 同一肩侧过肩 → 同一肩侧近似过肩。
- 机位只移动10度，景别、主体、动作阶段和构图均近似。

### 豁免与不适用

以下情况可以不满足30度，但必须记录具体依据：

- **同轴大景别变化**：同一观察轴线上，景别至少跨越两级，且镜头任务或动作阶段明确改变。
- **主体改变**：人物切到视线目标、关键道具、另一人物或环境威胁。
- **观察视角改变**：客观镜头切POV、关系镜头切主观细节。
- **时间或空间改变**：TIME CUT、SPACE CUT或场景重建。
- **关系结构显著改变**：双人关系镜头切单人心理特写，或机位高度／空间层次发生主导变化。
- **有意跳切或图形匹配**：用户明确采用，并说明节奏或图形目的。

“动作阶段变化”或“新增信息”本身不能单独豁免近似机位；必须同时存在足够的视觉变化。

## 景别差异与同轴切镜

统一景别级别从近到远为：

```text
ECU极近特写 → CU特写 → MCU近景 → MS中景
→ MLS中全景 → FS全景 → LS远景 → ELS大远景
```

“跨越两级”指前后级别索引差至少为2，例如：

- ECU极近特写 → MS中景。
- CU特写 → MS中景。
- MS中景 → FS全景。

同轴切镜的机位夹角可以接近0度，但必须同时满足：

1. 景别至少跨越两级。
2. 前后SHOT具有不同的独立镜头任务。
3. 动作结果和状态继承正确。
4. 同轴关系、摄影机方位和人物可见面已经通过`04`。

例如“正面眼部极近特写 → 同轴正面中景，开始表现整个人后退”属于合法的同轴大景别变化，不得为了满足30度强行改成侧面机位。

只变化一级时，必须同时明显改变角度、主体、观察视角、构图层次、人物关系或信息重点；否则属于近似镜头。

镜头内推近、拉远或变焦仍属于同一SHOT的运镜，不是CUT，也不使用30度规则。

## 标准两变量路径

标准路径要求每次CUT至少改变两个有效维度，其中至少一项来自视觉几何维度。

视觉几何维度：

1. 摄影机角度。
2. 景别。
3. 主要画面主体。
4. 观察视角。
5. 构图重心。
6. 摄影机高度。
7. 空间层次。
8. 人物关系。

第二项可以是另一视觉维度，也可以是：

9. 动作阶段。
10. 新增叙事信息。
11. 情绪或权力关系重点。

不能只依靠“动作阶段变化＋新增信息”，在几乎相同的机位和构图之间硬切。

## 主导变化路径

以下单一变化本身可以成为主导变化，但必须有独立镜头任务，并通过空间与连续性审核：

- 主要主体完全改变。
- 客观视角切为POV，或POV切回客观。
- 时间或空间发生明确跳变。
- 同轴景别至少跨越两级。
- 双人关系构图切为单人心理构图，人物关系和构图重心被重新定义。
- 用户明确设计有意跳切或图形匹配。

主导变化路径不是免检通道。必须记录：

```text
视觉差异路径：主导变化
主导变化类型：
30度适用性：豁免／不适用
豁免依据：
下一SHOT独立任务：
```

若主导变化声明与实际画面不符，CUT结论只能是“需返工”。

## 摄影机设计顺序

机位设计必须依赖`04`的空间事实，按以下顺序：

1. 当前镜头叙事任务。
2. 人物正在看谁、去哪里、做什么。
3. 人物身体和头部朝向。
4. 关系轴线、运动轴线与摄影机允许区。
5. 当前信息需要的景别、角度和焦点。
6. 与上一机位的视觉差异。
7. CUT后是否完整继承上一SHOT结果。

需要正脸时移动摄影机，不得让人物无理由转向镜头。

## 过肩、反打与主观镜头

### 过肩镜头

必须写清：

- 左肩还是右肩。
- 前景人物的姿态、朝向和视线。
- 前景是否虚焦，是否仍需承担信息。
- 清晰主体位于画面哪一侧。
- 相比上一机位的角度变化。
- 摄影机是否仍位于`04`锁定的同一轴线侧。

禁止上一镜正面拍人物，下一镜无几何说明地直接跳到正后方。

### 反打镜头

必须保持`04`锁定的屏幕左右和视线匹配，且新镜头承担新的反应、信息或权力关系任务。禁止只因换说话人就反打。

### POV镜头

前镜必须先建立人物视线和目标方向；POV内容必须与该人物实际可见范围一致。

## 状态与可见性前置条件

每个CUT必须通过`04-blocking-continuity.md`的两项审核：

1. **状态继承通过**：下一SHOT起始状态完整继承仍然成立的人物、动作、道具和场景状态。
2. **信息可见性通过**：当前景别、光线、焦点和遮挡确实能看到所描述的信息。

本文件不重复维护状态字段清单和可见性细则；若`04`判定失败，本CUT自动失败。

## 每个SHOT强制格式

```markdown
### SHOT XX｜时长

- 镜头任务：本镜独立负责什么。
- 空间状态引用：04中的场景／SHOT状态编号。
- 景别：
- 摄影机位置：相对于人物、场景锚点和轴线。
- 摄影机角度：
- 人物位置与朝向：引用04并写本镜可见关系。
- 起始状态：引用04中的上一SHOT继承状态。
- 镜头内容：按真实时间顺序。
- CUT点：具体动作、视线、台词、反应、遮挡、时间或空间节点。
- CUT类型：普通／MATCH-ON-ACTION／REACTION／EYELINE／INSERT／SPACE／TIME／POV／END。
- CUT理由：下一SHOT的新任务；终镜写本场／本集结束。
- CUT前结束状态：写结果并同步回04状态表。
- 下一SHOT起始状态：引用04的继承结果；终镜可写无／已知下一集状态。
- 视觉差异路径：标准两变量／主导变化；终镜写不适用。
- 有效差异：列出改变的维度或主导变化类型。
- 30度适用性：适用／豁免／不适用；适用时写机位夹角，豁免时写依据。
- 几何检查：180度轴线、摄影机允许区、景别差异、过肩／反打关系。
- CUT结论：通过／需返工。
```

禁止写“适时切镜”“自然切镜”“情绪到位后切”。CUT点必须是可识别的具体节点。

## CUT审核流程

### 第一步：当前节点是否形成结果

确认动作、视线、信息、情绪、对白、时间或空间节点已经成立。未成立则继续当前SHOT。

### 第二步：下一镜是否具有独立任务

必须出现新主体、新阶段、新信息、新视角、新人物关系、新情绪重点或新空间任务。没有则不CUT。

### 第三步：空间与状态是否通过04

确认位置、轴线、屏幕方向、动作进度、道具状态和信息可见性均通过。任一失败则返工。

### 第四步：选择视觉差异路径

先判断使用“标准两变量路径”还是“主导变化路径”，不得把30度、景别和两变量机械叠加成三个同时必过的门槛。

### 第五步：判断30度是否适用

- 适用：检查主要主体处的机位夹角是否达到30度，并确认没有越轴。
- 豁免／不适用：写明同轴大景别、主体／POV／时间／空间变化或其他有效依据。
- 任一情况下都要排除近似构图和无任务跳切。

### 第六步：CUT类型是否与动作进度一致

动作未完成只能使用MATCH-ON-ACTION；动作已完成不得误标MATCH。

六步全部通过，CUT才成立。

## 故事板与视频提示词约束

- 九宫格、十二宫格或其他格数不等于SHOT数量。
- 一个SHOT可以占多个格子；一个SEG可以包含多个已确认SHOT。
- 故事板和视频提示词必须保留已通过的SHOT边界、CUT点和类型。
- 下游模型负载过高时拆分SEG，不删除合法CUT。
- 普通多镜头流程使用状态继承，不默认复制上一尾帧；首尾帧工作流仅在用户明确采用I2V、FLF2V或视频延长时启用。
